SceneBlock은 촬영 전에 인물이 어디로 움직이고, 어떤 자세를 취하고, 카메라가 어디를 볼지 실험하는 도구입니다. 완성 영화를 만드는 대신 장면의 움직임과 구도를 빠르게 확인합니다.

AI 없이도 바로 시작할 수 있어요.
기본 편집에는 가입이나 AI 모델 설치가 필요 없습니다. AI를 쓰고 싶을 때만 AI 연결 안내를 따라 하세요. 컴퓨터와 마우스로 편집하면 편리합니다.

1. 첫 장면 만들어 보기

  1. 편집 화면 왼쪽의 장면 설명에 아래 예문을 입력하세요.
  2. 구성 방식을 로컬 규칙 · 설치 없이로 선택하세요.
  3. 로컬 규칙으로 구성을 누르세요. 정해진 규칙으로 장면을 만듭니다. AI가 문장을 자유롭게 해석하는 방식과는 차이가 있습니다.
  4. 화면의 인물을 클릭한 뒤 오른쪽에서 위치와 방향을 바꿔 보세요.
  5. 아래 ▶ 재생을 눌러 움직임을 확인하고 프로젝트 저장으로 보관하세요.

2. 화면과 마우스 익히기

  • 왼쪽: 장면 설명, 구성 방식, 인물·소품 목록, 카메라 목록이 있습니다.
  • 가운데: 인물과 소품을 보며 장면을 편집합니다.
  • 오른쪽: 선택한 인물·소품·카메라의 설정을 바꿉니다. 먼저 바꿀 대상을 클릭하세요.
  • 아래: 시간표인 ‘타임라인’입니다. 동작과 카메라가 언제 시작하고 끝나는지 보여 줍니다.

3. 동선·동작·자세 바꾸기

인물과 소품 추가

왼쪽 + 인물로 인물을 추가하세요. 소품은 추가할 소품에서 종류를 고르고 + 소품을 누르세요. 대상을 선택하고 오른쪽 설정에서 이름·위치 등을 바꿉니다.

동선: 인물이 지나갈 길

  1. 움직일 인물을 선택하세요.
  2. 동선 그리기에 마우스를 올려 직선 또는 곡선을 고르세요.
  3. 바닥을 차례로 클릭해 지나갈 점을 찍으세요. 위에서 보기를 쓰면 길을 보기 쉽습니다.
  4. 점을 끌어서 길을 수정하세요. Esc로 그리기를 마치세요.
  5. 걷는 동작을 배치하고 재생해 보세요. 걷는 구간을 길게 하면 도착하는 시간도 늦어집니다.

인물을 직접 회전하면 ‘동선을 따라 바라보기’가 꺼집니다. 다시 이동 방향을 보게 하려면 해당 옵션을 켜세요. 인물 전체와 소품의 회전은 Y축, 즉 바닥 위에서 방향을 돌리는 회전입니다.

동작: 걷기처럼 일정 시간 하는 행동

인물을 선택하고 오른쪽에서 기본 동작을 고르세요. 아래 시간표의 막대는 그 동작이 이어지는 구간입니다. 막대 가운데를 끌면 시작 시간이 바뀌고, 양 끝을 끌면 길이가 바뀝니다. 기본 동작에 팔 등 특정 부위의 자세를 더할 때는 추가 레이어를 사용합니다. 레이어는 같은 인물 아래에 쌓이는 별도 편집 줄입니다.

자세: 특정 순간의 몸 모양

  1. 아래 시간 조절 막대를 움직여 자세를 남길 시간을 고르세요.
  2. 인물과 적용 부위(예: 오른팔)를 선택하세요.
  3. 제공된 자세를 쓴다면 프리셋을 선택하고 선택 프리셋을 현재 시간에 기록을 누르세요.
  4. 직접 바꾸려면 현재 자세에서 관절 편집을 누르세요. 처음부터 만들려면 중립 자세에서 새로 만들기를 누르세요.
  5. 관절 점이나 목록에서 관절을 선택하고 회전축 또는 각도 숫자를 조절하세요.
  6. 편집한 자세 저장을 누르세요. 저장 전에는 임시 편집 상태입니다. 시간 이동이나 재생 전에 저장 또는 편집 취소를 하세요.
손 들기 연습

0초에서 팔을 내린 자세를 기록하고, 2초에서 팔을 든 자세를 기록하세요. 두 자세 사이가 이어지는지 재생해서 확인하세요. 자세를 기록한 표시는 타임라인의 다이아몬드입니다. 반투명 인물은 자세를 미리 보여 주는 표시입니다.

정지 자세 프리셋은 AI가 새로 만든 동작이 아닙니다. 발이 바닥에 정확히 붙도록 자동 보정하는 고급 기능은 현재 지원하지 않습니다.

4. 카메라와 타이밍 맞추기

  1. 장면 편집에서 마우스로 원하는 구도를 잡으세요.
  2. 왼쪽 + 현재 시점을 카메라로를 눌러 구도를 저장하세요.
  3. 다른 구도도 같은 방식으로 추가하세요. 왼쪽 카메라 목록에서 선택해 오른쪽 설정을 조정할 수 있습니다.
  4. 카메라 컷은 어떤 시간에 어떤 카메라를 쓸지 정하는 구간입니다. 아래 카메라 컷 막대의 경계를 조절하고, 컷 연결 창을 사용했다면 컷 적용을 누르세요.
  5. 촬영 미리보기에서 재생해 실제 컷 순서와 구도를 확인하세요.

장면 전체 길이는 아래 길이 숫자로 바꿉니다. 동작·자세·카메라를 조금씩 수정하고 재생하는 과정을 반복하세요. 움직이는 카메라는 선택한 카메라의 움직임 설정을 확인하세요.

5. AI 연결하기

AI는 문장으로 설명한 장면의 구성안을 만들어 줍니다. 먼저 미리 보고, 마음에 들 때 현재 장면에 적용합니다.

이미 ‘연결됨 · 준비 완료’가 보이나요?
설치를 반복하지 말고 4단계: AI로 장면 만들기로 이동하세요. ‘준비 완료’는 연결 상태를 뜻합니다. 장면 생성 성공 여부는 실제 구성안을 받아 확인해야 합니다.

시작 전에, 서로 다른 두 가지를 준비해요

  • SceneBlock 연결 프로그램: 웹 화면과 내 PC의 AI 도구를 이어 주는 다리입니다. TTS용 연결 앱과 다릅니다.
  • Codex 또는 Claude Code: 실제 AI 작업을 하는 공식 도구입니다. 둘 중 사용할 하나를 설치하고 로그인하면 됩니다. ‘CLI’는 명령을 입력해 사용하는 프로그램이라는 뜻입니다.

아래 설치 안내는 현재 제공되는 Windows x64 기준입니다. AI 모델을 직접 내려받을 필요는 없습니다. 사용 중인 계정의 인증 방식과 이용 한도가 적용되며, API 인증을 쓰면 별도 API 요금이 생길 수 있습니다. 구독만으로 항상 무료라고 가정하지 마세요.

1단계 · SceneBlock 연결 프로그램 설치

  1. 편집 화면 왼쪽의 AI 연결 · 설정을 누르세요. 이미 연결되었다면 AI 연결 설정 · 연결됨으로 보일 수 있습니다.
  2. 사용할 AI에서 ChatGPT Codex 또는 Claude Code를 고르세요.
  3. Windows AI 설치 프로그램 다운로드를 누르세요.
  4. 브라우저 다운로드 목록에서 받은 EXE를 실행하세요.
  5. 설치 창에서 설치 / 연결 복구를 누르고 완료되면 설치 창을 닫으세요.

현재 설치기는 서명되지 않은 베타 설치기입니다. Windows가 경고하면 받은 출처와 파일을 확인하세요. 출처를 확인할 수 없으면 진행하지 마세요. 압축 해제나 연결 코드 입력은 필요하지 않습니다.

2단계 · 공식 AI 도구 설치와 로그인

이미 해당 도구를 설치했다면 설치는 건너뛰세요. 해당 도구에도 로그인했다면 로그인도 건너뛰세요. ChatGPT·Claude 웹사이트에 로그인한 것만으로는 이 준비가 끝나지 않습니다.

  1. AI 설정 창의 선택한 AI 도구 설치·로그인 항목을 보세요.
  2. Windows 검색에서 PowerShell을 찾아 여세요.
  3. SceneBlock 설정 창에 표시된 설치 명령을 복사해 PowerShell에 붙여 넣고 Enter를 누르세요. 설치가 끝날 때까지 기다리세요.
  4. 이어서 같은 설정 창의 로그인 명령을 복사해 실행하세요.
  5. 열리는 공식 로그인 안내를 따라 사용할 계정으로 로그인하세요.

설치·로그인 명령은 설정 창에서 선택한 AI에 맞춰 표시됩니다. 명령 전체를 한 번에 여러 줄 실행하지 말고 하나씩 실행하세요. 로그인 안내에 추가 입력이 나오면 그 안내를 따르세요. AI 비밀번호나 인증키를 SceneBlock에 직접 입력하지 않습니다.

로그인 명령의 예: Codex는 codex login, Claude Code는 claude auth login입니다. 설치 명령과 공식 안내 링크는 앱의 설정 창에서 확인하세요.

3단계 · SceneBlock에서 연결 확인

  1. 브라우저의 SceneBlock AI 설정 창으로 돌아오세요.
  2. AI 연결을 누르세요.
  3. 브라우저가 앱을 열지 물으면 SceneBlock 연결 앱인지 확인하고 열기를 허용하세요.
  4. 로컬 사이트 승인 창에서는 연결을 요청한 사이트 주소가 현재 사용 중인 SceneBlock 주소인지 확인하세요.
  5. 브라우저가 로컬 네트워크 접근을 물으면 연결을 허용하세요. 이 권한은 브라우저가 내 PC의 연결 프로그램과 통신할 때 쓰입니다.
  6. 연결됨과 준비 완료를 확인하세요. 설치·로그인 후 상태가 그대로면 설치·로그인 다시 확인을 누르세요.
  7. 준비되면 설정 창을 닫으세요. 설치 창이나 PowerShell 창을 계속 열어 둘 필요는 없습니다.

설정 창을 닫는 것은 연결 해제가 아닙니다. 연결이 끊겼다면 AI 연결을 다시 누르세요. 연결 프로그램은 뒤에서 실행되며 사용하지 않을 때 자동 종료될 수 있습니다.

4단계 · AI로 장면 만들기

  1. 왼쪽 구성 방식을 ChatGPT Codex 또는 Claude Code로 바꾸세요. 준비한 AI와 같은 것을 고르세요.
  2. 장면 설명과 인물·소품·카메라 요약을 선택한 AI에 전송 항목을 읽고 동의한다면 체크하세요. 공유하고 싶지 않은 정보는 장면에 넣지 마세요.
  3. 왼쪽 장면 설명에 만들고 싶은 장면을 입력하세요.
  4. 장면 구성을 누르고 기다리세요. 중단하려면 요청 취소를 누르세요.
  5. AI 구성안 검토가 나오면 3D 화면과 미리보기 시간을 움직여 결과를 확인하세요.
  6. 마음에 들면 현재 장면에 적용, 다시 만들고 싶으면 구성안 버리기를 누르세요. 버린 뒤 설명을 고쳐 다시 구성할 수 있습니다.
가장 많이 헷갈리는 부분
AI가 연결되어 있어도 구성 방식이 로컬 규칙 · 설치 없이이면 AI를 사용하지 않습니다. 연결 확인 후 반드시 구성 방식도 바꾸세요. 구성안을 받기만 하면 현재 프로젝트에 확정되지 않습니다. 현재 장면에 적용까지 눌러야 반영됩니다.
AI에게 이렇게 설명해 보세요

10초 장면. 카페에서 민수는 왼쪽, 지우는 오른쪽에 있다. 민수가 0초부터 4초까지 지우에게 걸어간 뒤 멈춘다. 지우는 4초에 오른손을 든다. 0~4초는 두 사람이 보이는 넓은 구도, 4~10초는 지우가 잘 보이는 구도로 구성해 줘.

누가, 어디에서, 몇 초에, 무엇을 하는지 나눠 쓰면 의도를 전달하기 쉽습니다. 결과가 요청과 다르면 편집하거나 설명을 고쳐 다시 구성하세요. 복잡한 동작을 모두 정확히 구현한다고 보장하지는 않습니다.

Kimodo도 설치해야 하나요?

아니요. 장면 편집과 Codex·Claude Code 장면 구성에는 필요하지 않습니다. 오른쪽의 고급 기능 · Kimodo (선택)은 새 동작 생성을 위한 별도 기능입니다. 모델 접근 승인과 큰 용량의 모델·별도 실행 환경이 필요하며 실제 새 추론은 아직 검증하지 않았습니다. ‘미리 생성된 공식 예제 적용’은 이미 만들어진 결과를 불러옵니다.

6. 프로젝트 저장과 영상 내보내기

  • 프로젝트 저장: 다시 편집할 수 있는 JSON 파일을 저장합니다. 중요한 변경 후 자주 저장하세요.
  • 열기: 저장한 프로젝트 JSON 파일을 불러옵니다.
  • 영상 내보내기: 카메라 컷 순서로 WebM 영상을 만듭니다. 먼저 촬영 미리보기로 구도를 확인하세요. 영상 파일로는 장면을 다시 편집할 수 없으므로 JSON도 함께 보관하세요.
  • 복구 안내: 같은 사이트·브라우저에 남아 있는 로컬 복구본을 불러올 수 있습니다. 브라우저 데이터를 지우거나 다른 브라우저를 쓰면 복구되지 않을 수 있습니다. 파일 저장을 대신하지 않습니다.

위쪽 프로젝트 이름을 눌러 알아보기 쉬운 이름으로 바꿔 보세요. 실수했다면 실행 취소, 취소한 작업을 되돌리려면 다시 실행을 사용하세요.

7. 막혔을 때 확인하기

AI에 연결했는데 로컬 규칙으로 구성돼요.

왼쪽 구성 방식을 확인하세요. ChatGPT Codex 또는 Claude Code를 선택해야 합니다. AI 설정의 사용할 AI와 왼쪽 구성 방식은 역할이 다릅니다.

‘설치 필요’, ‘업데이트 필요’, ‘로그인 필요’가 보여요.

어떤 도구의 상태인지 먼저 확인하세요. SceneBlock 연결 프로그램과 공식 AI 도구는 별개입니다. 설정 창의 안내에 따라 해당 도구를 준비한 뒤 설치·로그인 다시 확인을 누르세요. 로그인은 공식 도구의 계정 로그인이 필요합니다.

앱이 열리지 않거나 연결 시간이 초과돼요.
  1. 앱 열기·사이트 승인 창이 다른 창 뒤에 있는지 확인하세요.
  2. 브라우저의 사이트 권한에서 로컬 네트워크 접근이 차단되어 있지 않은지 확인하세요. 메뉴 이름은 브라우저마다 다릅니다.
  3. 설치했다면 앱 열기 다시 요청을 누르세요.
  4. 앱을 찾을 수 없다고 나오면 SceneBlock 설치 프로그램의 설치 / 연결 복구를 사용하세요.

네트워크 오류만으로 미설치라고 단정하지 마세요. 사용 중인 사이트 주소가 맞는지도 확인하세요.

준비 완료인데 장면이 생성되지 않아요.

구성 방식, 전송 동의 체크, 빈 장면 설명 여부를 차례로 확인하세요. 화면에 나온 오류를 읽고 계정 로그인·이용 한도·네트워크 상태를 확인하세요. 기다리던 요청을 취소하려면 요청 취소를 누르세요. 실패 원인을 확인하지 않고 설치를 계속 반복할 필요는 없습니다.

AI 결과가 마음에 들지 않거나 잘못 적용했어요.

적용 전이라면 구성안 버리기를 누르고 설명을 고쳐 다시 만드세요. 적용한 뒤라면 실행 취소를 사용하거나 저장한 프로젝트를 여세요. 새 구성 전에 중요한 프로젝트를 저장하는 습관이 좋습니다.

자세를 바꿨는데 저장되지 않았어요.

관절 편집은 먼저 초안으로 보입니다. 편집한 자세 저장을 눌렀는지 확인하세요. 적용 부위와 현재 시간, 선택한 인물도 확인하세요.
