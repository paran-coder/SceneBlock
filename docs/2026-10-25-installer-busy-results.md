# SceneBlock v2.13.2 / 연결기 v2.10.2
브라우저를 닫아도 설치가 사용 중으로 막히는 문제를 수정했다. 기존 Busy는 MainModule 조회 실패 시 모든 node/날짜이름 프로세스를 소유 프로세스로 간주했고 이름 조회 실패도 무조건 busy였다. 권한 제한으로 실제 사용자 프로세스의 경로를 확정할 수 없었으므로 그 PC의 단일 원인을 단정하지 않는다. 한편 새로고침 복구를 위해 탭 종료 즉시 release하지 않는30분 lease가 실제 연결기를 남길 수 있다.

새 판정은 QueryFullProcessImageName의 제한된 조회권한으로 얻은 정확한 실행 경로와 해당 버전의 실행 파일 잠금을 사용한다. 다른 Node/Codex/Claude나 이름만 날짜로 시작하는 앱은 무조건 막지 않는다. 자체 설치 관리자 경로를 제외하고, 자기 설치파일 잠금/검사실패는 계속 보수적으로 막는다. 막힌 버전의 정확한 폴더를 안내한다.

설치창에 연결 프로그램 종료 버튼을 추가했다. 완전한 소유권/모든 payload hash가 확인된 설치의 정확한 node.exe 경로만 대상으로 PID와 경로를 미리 표시하고 확인 후 종료한다. 실행 직전 PID의 경로도 재검사한다. 진행중 AI 요청 취소 및 탭 재연결 필요 안내가 있으며 취소하면 종료하지 않는다. 다른 프로그램/임의프로세스 종료 기능은 없다. 실제 사용자PC의 프로세스 종료/설치/로그인 변경은 이번 작업에서 실행하지 않았다.

격리 판정fixture6, 기존자동263 통과. native/payload/다운로드4/빌드는 최종 결과 참조. 실제 실행중 연결기 종료 버튼의 사용자PC 동작은 미실행이므로 사용자가 새 설치기에서 확인해야 한다. 종료 후 설치 · 업데이트하고 웹에서 AI 연결한다. 기존 AI/수동 기능과 캐릭터 외형은 유지한다. 자체평가8/10(실제프로세스 종료 미실행).
