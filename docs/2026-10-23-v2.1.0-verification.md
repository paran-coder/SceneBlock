# SceneBlock v2.1.0 검증 기록

이 릴리스는 동선·행동·포즈·카메라·타임라인을 보완한 브라우저 연출 기능의 1차 릴리스입니다. 원본 Git 저장소 SceneBlock과 기존 배포 ZIP은 보존했습니다. 사용자 승인 후 신규 버전 안의 복사본만 수정했습니다.

## 확인한 결과

- 단위 테스트 44/44: 기존 파일 저장·모션 재생, 순차 클립/빈 구간/검증, 카메라 추적/운용/가감속, 비정렬 컷 끝점, 모션 속도와 길이, 타임라인 이동/트림 경계, 포즈 세계 좌표 변환, 관절 보정, 포즈 로드 실패/재시도, 기존 JSON 변환 ID 충돌 방지.
- 실제 Chrome 통합 검사: 4개 캐릭터 파일 로드, 바닥 클릭으로 경유점 생성, 번호 핸들 드래그, Undo/Redo, 재생 중 동선 편집 시 일시정지, 세 행동 구간 생성, 행동 클립 이동/트림, 카메라 컷 트림, 121개 포즈 선택과 실제 캐릭터 교체/관절 보정, 추적 카메라, 촬영 시 가이드 숨김, JSON 다운로드와 파일 선택 복원, 인물 삭제 시 추적 참조 정리/Undo, 모델 없는 공식 예제, 영상 내보내기.
- 실제 WebM 다운로드를 ffprobe로 검사: VP8, 1056×594, 1초, 디코딩된 30프레임.
- 기존 카페 장면 구성·저장·예제·영상 회귀 검사 6개 흐름 통과.
- 기본 사용 중 외부 서비스·127.0.0.1:8765 엔진 요청 없음. JavaScript 페이지 오류 없음.
- production build 및 배포 정적 파일 검사 통과. 보안 헤더는 vercel.json과 동일하게 적용한 로컬 HTTP 서버에서 검사했습니다.

## 구현 검토에서 보완한 사항

포즈가 기본 동작 위에 겹쳐 변형되는 문제, Undo/Open 후 이전 actor 참조에 경로를 쓰는 문제, 생성 모션 속도에 맞지 않는 클립 길이, 타임라인 선택과 ID 변환 충돌, 경로 끝 좌표 수정 시 경유점을 잃는 문제, 포즈 로드 실패를 성공으로 취급하는 문제, 내보내기 중 편집이 가능한 문제를 수정했습니다. 폴더 밖 사용자 소스나 전역 설정은 변경하지 않았습니다.

## 제한 사항

실제 원격 GitHub/Vercel 업데이트와 배포 URL 검사는 수행하지 않았습니다. 새 Kimodo 모델 다운로드·GPU 추론·HTTPS→로컬 엔진 연결도 수행하지 않았습니다. 동선과 포즈를 AI 제약으로 보내는 기능은 이번 릴리스 범위에 포함하지 않았습니다. 모델 기반 생성이 검증됐다고 해석하면 안 됩니다.

포즈와 기본 행동은 구간 경계에서 전환하며 블렌딩·IK·발 접지 보정은 없습니다. 모든 캐릭터 키는 1.75m로 정규화합니다. 자연어는 규칙 파서, 출력은 편집 화면 크기의 WebM이며 자동 저장·외부 모델 가져오기·원본 프로젝트 호환·자동 장면 검사는 제공하지 않습니다.

자체 평가: 계산/저장 9/10, 동선·타임라인 직접 조작 9/10, 포즈/카메라 통합 9/10. 실제 보행의 자연스러움과 원본 기능 동등성은 별도 보완 대상이므로 전체 원본 통합 완료라고 평가하지 않습니다.

최종 패키지 확인: 별도 소스 복사본에서 npm ci → production build → 단위 테스트 44/44 → 정적 파일 검사 통과. 선택 커넥터 테스트 4/4 통과. 원본 SceneBlock Git 작업 트리는 변경 없음. 신규 ZIP의 512개 파일에서 node_modules/dist/.git/Python 바이트코드/모델 가중치/실행 파일이 없는지 검사했습니다. 다운로드 엔진 ZIP은 기존 검증된 v2.0.0 소스를 그대로 포함하며 새 AI 생성 지원 범위는 늘어나지 않았습니다.
