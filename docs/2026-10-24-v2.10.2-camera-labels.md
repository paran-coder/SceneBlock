# SceneBlock v2.10.2 — 카메라 이름표와 대상 구분

## 변경
- 중앙 카메라 위에 현재 카메라 이름을 DOM 이름표로 표시. 선택 카메라 강조, 이름표 클릭으로 선택. 이름 변경은 장면·목록·타임라인·작은 뷰어·선택 대상 표시에 동기화.
- 이름표는 3D 카메라 위치를 화면에 투영해 배치하며 촬영 모드/출력에서 숨김. 미니 뷰어와 출력 영상은 WebGL 캔버스만 사용하므로 DOM 이름표가 포함되지 않음.
- 오른쪽 인물 설정/인물 연출 또는 카메라 설정/카메라 연출. 탭 위 선택한 인물/카메라와 이름을 표시. 이전 종료 구도 버튼을 기본 설정에서 기존 프로젝트용 고급 항목으로 이동.
- 탭 재렌더에서 선택 대상/종료 구도 버튼 중복·유실 방지. 기존 초안 보호 유지.

- 새 브라우저 검사의 이름표 미표시 실패를 먼저 확인한 뒤 구현.
- 자동 테스트 147/147 통과.
- 새 실제 Chrome 검사 5종: 이름표/대상별 탭, 인물·카메라 항목 분리/선택 강조, 이름 변경 5곳 동기화와 안전한 텍스트 처리, 패널 재렌더 중복 방지, 촬영 모드 숨김·1280px 레이아웃.
- 카메라·탭 기존 통합 9종, 초안 보호 10종, 자유 회전 4종 통과. 총 브라우저 28개 항목 통과.
- 실제 구도 동선 영상 5초 출력 통과. 기존 파일은 dev/2026-10-24-camera-labels-v2.10.1-backup에 보존.
