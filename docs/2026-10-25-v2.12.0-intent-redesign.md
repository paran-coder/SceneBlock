# SceneBlock v2.12.0 — 명시적 AI 초안 구조

## 변경과 제거
- v2.11.0/2.11.1의 단어·표시 이름에 따른 좌석 추정/180도 회전/정면 강제/동작 레이어 OFF/카메라 이름 치환을 제거했다. 이전 모듈은 빈 retired stub로 교체했으며 원본은 dev/2026-10-25-ai-redesign-v2.11.1-backup에 보존했다.
- 원문을 결정적인 source units(UTF16 spans)로 나누고, AI가 requirementIds/entities/actions/relations/shots/coverage를 반환한다. 동작으로 촬영 요구를 충족시킬 수 없도록 종류별 참조 검증을 한다.
- 새 컴파일러는 이름이나 원문 키워드로 관계를 추측하지 않는다. 실제 지원 범위를 sceneIntentCapabilities로 알리고 명시적 좌석ID·대상ID·시간·화면 대상을 사용한다.
- 좌석 치수는 카탈로그 anchor(.51/.52/.56)와 요청값에서 계산한다. 현재 actor-standard만 지원하며 기존 저장 필드는 generic legacy-bindings에서 계속 재생한다. Stage가 AI 검사 모듈을 import하지 않는다.
- 명시적 avoid의 평면 단일 이동은 회전 장애물 경계로 우회 후보를 계산한다. 경로 끝점/꺾임 시간의 충돌, 서로 다른 시간 교차, 머리 높이 장애물, 카메라 내부 충돌을 검사한다. 가림 허용은 벽 내부 카메라 배치를 허용하지 않는다.
- 미지원/모호/위반은 적용 차단. 명시 생략한 요구는 객체/행동에서 제외하고 종속 참조가 남으면 차단한다. 근사 구도는 별도 확인 체크를 받아 적용한다. 생략 결과는 aiDraftReceipt에 저장한다.

## 사용자 흐름
기본 예시 · AI 없이: 일부 단어를 반영한 정해진 예시이며 긴 설명을 이해하지 않는다고 사전 안내한다.
AI 초안: 설명 해석 → 원문 요구별 결과·질문 확인 → 지원 범위 계산 → 미리보기 → 적용/버리기. 연결하면 방법 선택을 AI로 전환하되 생성은 사용자가 별도 실행한다.
연결됨은 PC/CLI 통신 상태이며 장면 품질 성공 표시가 아니다. 설치 전에도 미지원 항목을 볼 수 있다.

## 지원 경계
현재 기본 동작과 actor-standard, 기본 소품9종, 한 인물의 단일 이동구간, 명시적 좌석·정적 방향/도착 방향, 정지 카메라의 전신/공간 구도를 처리한다. 상세 기능 목록은 compiler capability를 기준으로 한다.
물건 전달·정확한 시선/표정·의상/날씨·여러 독립 이동·동적 촬영·세밀한 손 구도는 미지원 상태로 남기며 다른 동작으로 바꾸지 않는다. 동적 AI 촬영 미지원은 기존 수동 카메라 움직임 기능의 삭제가 아니다.
검사는 표준 인물과 보수적인 모델 경계 기반이며 관절/손 단위 물리나 미적 완성도를 보장하지 않는다. 복잡한 장면은 조건 위반/미지원으로 차단될 수 있다.

## 연결 프로그램2.8.0
health responseFormats로 scene-intent-v1을 협상한다. 새 웹은 /generate-intent만 사용하며 구형 연결기에 /generate로 fallback하지 않는다. 이전 /generate 계약은 유지한다. 새 요청64KiB/기존32KiB의 한도는 최대 한국어 입력을 고려해 분리했다.
PC2.7.0은 새 AI 초안을 쓰려면2.8.0 업데이트가 필요하다. 기본 예시/직접 편집은 계속 가능하다. 이번 작업은 설치기 생성·workspace 격리 self-test만 했으며 실제 사용자 설치/레지스트리/배포는 변경하지 않았다.
