# SceneBlock v2.10.1 — 업로드 전 검수 결함 수정

## 수정
1. 기록 전 초안이 남아 있으면 타임라인 pointerdown/pointerup/click/dblclick/keydown을 캡처 단계에서 차단합니다. 마우스/Enter 선택, 드래그·Delete로 카메라와 시간이 바뀌거나 프로젝트가 변경되는 것을 막습니다.
2. 공통 컷 선택·대상 선택·시간 변경 콜백에도 초안 검사를 추가했습니다.
3. record()는 초안 카메라 ID와 시간의 일치를 확인하고, 일치하지 않으면 기록하지 않습니다. 기존 초안의 시간은 후속 편집 중 다시 덮어쓰지 않습니다.
4. inspector 내부 버튼을 대체로 허용하던 예외를 제거하고, 초안 중 mutate() 자체도 차단했습니다. 초안 편집/기록/취소, 이동·회전 도구, 뷰어·탭 등 필요한 조작은 유지합니다. 동선·프리셋·구도 구조 변경은 기록/취소 후 가능합니다.
