# SceneBlock v2.14.5

상단 메뉴 순서를 카메라 표시 → 동선 표시 → 위에서 보기 → 동선 그리기 → 동선 지우기로 정리했습니다. 좁은 화면의 더보기 안에서도 같은 순서입니다.
동선 표시는 기본 켜짐이며, 저장된 인물/카메라 동선을 편집 화면에서 켜고 끕니다. 프로젝트의 동선 데이터는 삭제하거나 변경하지 않습니다. 촬영 미리보기/카메라 뷰어/출력에는 안내선을 넣지 않습니다. 동선 그리기를 시작하면 안내선을 켜고, 그리는 중 표시를 끄면 현재 그리기를 마친 뒤 숨깁니다. 표시 상태는 현재 편집 세션에서만 유지합니다.

기존 ? 호버 도움말, 타임라인 스크롤, 카메라 표시와 화각 선은 유지합니다.
검증: 실제 Chrome 16흐름 통과, 페이지 오류0. 넓고 좁은 화면의 순서, 프로젝트 불변, 카메라 표시 독립성/화각 선, 미리보기 안내선 제외(캔버스 이미지 동일), 그리기 중 표시 전환, 기존 도움말/타임라인/편집 조작 확인. 빌드와 정적 패키지 검사 통과. 전체 Node/영상 출력/실제 AI 계정 호출/공개 배포는 이번 버전에서 재실행하지 않았습니다. 자체평가9/10.
