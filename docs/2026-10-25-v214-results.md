# SceneBlock v2.14.0 변경 및 검증 · 2026-10-25

## 적용
- 범용 PoseBlock 3D v2 JSON: poses의 단일 포즈와 scenes.state.chars의 복수 인물을 읽습니다. 임의 이름 지원, 포즈별 기존 인물 지정, 가져오지 않음, 적용 구간/부위/원본 중립 자세 선택, 위치/방향은 명시 선택입니다. 원본 sample 두 파일은 형식 참고일 뿐 번들 프리셋으로 사용하지 않았습니다.
- 가져온 포즈는 프로젝트의 새 레이어에 포함되어 저장/열기, 실행 취소/다시 실행, 관절 보정과 영상 출력에 사용됩니다. 모델 프레임에서 관절 계층을 누적한 뒤 대상 뼈대의 bind/부모 축으로 변환합니다. 잘못된 회전값·중복 대상·용량/항목/시간 범위를 검사합니다.
- 카메라 생성 후 해당 시점에서 편집하고 구도를 기록합니다. 새 카메라는 타임라인 미배치 행에 즉시 나타납니다. 구간 추가 창에서 겹침을 확인해야 기존 컷 일부를 교체하며 구간 밖은 보존합니다. 카메라 자체 형상이 자신의 시점을 가리지 않도록 처리했습니다.
- 항목별 ? 도움말(클릭/바깥 클릭/Esc), 대상·시간·모드 상태줄과 완료/취소, 요소 검색/종류 필터, 좌우 패널 접기, 조절 가능한 타임라인 높이, 인물별 레이어 접기, W/E 도구 전환, 소품/생성 입력 순서, AI 설치 안내 접기를 적용했습니다. 상태·오류·전송 동의·편집 초안은 계속 보입니다.
- 내보내기 전 실제 해상도/FPS/길이/WebM/영상 전용 요약, 인코딩 취소, 저장 경로까지 취소 신호 확인을 추가했습니다. 파일명은 기존 OS 저장창에서 선택합니다.
- 저장 상태는 프로젝트 변경 시 계산해 캐시합니다. 브라우저 복구는 파일 저장과 구분하며 원본 모델/XYZ 조작/수동 편집은 유지합니다.

## 검증
- Node 자동 테스트 275/275 통과(기존 263 + 새 12). 최초 sandbox에서 로컬 HTTP 5건 EACCES 후 허용된 로컬 실행으로 전체 재검증했습니다.
- 실제 Chrome 새 워크플로 15, 기존 XYZ 회전/저장/영상 4, 카메라·포즈 9, AI 연결 복구 mock 7, AI 렌더 fixture 3: 총 38 흐름 통과, pageerror 0.
- 실제 1366×768, 1024×768, 800×768 화면 확인 및 가로 문서 넘침 검사 통과. 800px에서는 패널을 겹쳐 여는 방식입니다.
- 가져온 포즈+새 컷을 포함한 WebM 2초/60프레임 ffprobe 디코딩, 기존 AI fixture 영상 8초/240프레임 확인. 기존 회전/카메라 영상도 출력했습니다.
- npm run build 및 npm run check:package 통과. 독립 코드 리뷰의 취소 경로와 새 장면 상태 캐시 지적을 재현 테스트로 확인 후 수정했습니다.

## 한계와 보존
PoseBlock JSON에는 원본 뼈대 기준축/기본 형상이 없어 근사 변환입니다. T 자세/팔 내림 보정을 선택하며 정밀 손발 접촉·원본 외형·키·카메라·소품은 완전 재현하지 않습니다. 원본 PoseBlock 프로그램과의 정량적 자세 일치 평가는 하지 않았습니다.
실제 AI 계정 자연어 품질·장시간 절전·사용자 PC 설치·레지스트리·GitHub/Vercel 배포는 미실행입니다. 연결기는 v2.10.3 그대로입니다. 모델 자산, sample 원본, 독립 SceneBlock Git, 기존 배포 ZIP/기록은 보존했습니다. 브라우저 파일 선택기 검증은 호스트 API 단위 검사와 실제 Chrome 다운로드/열기 기준이며 사용자 네이티브 저장창 전 과정은 별도 확인이 필요합니다.
