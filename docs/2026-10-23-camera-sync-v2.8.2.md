# SceneBlock-v2.8.2 카메라 운용 동기화

승인 범위: 타임라인 컷 선택 또는 촬영 구도 목록 선택 후 운용을 변경하면 같은 카메라 움직임과 타임라인에 즉시 반영.
추가 프리셋, 자동 재생, 컷별 독립 움직임으로의 데이터 구조 변경은 제외한다.

기존 파일 변경: app.mjs는 목록 운용 표시와 컷 선택 동기화, directing-ui.mjs는 타임라인 운용 이름·툴팁·접근성 이름 및 적용 알림·즉시 stage 갱신. package.json·lock·index.html은 v2.8.2 표기.
원본 5개 파일은 2026-10-23-camera-sync-v2.8.1-backup에 먼저 복사.

- [x] 코드·브라우저 원인 확인: 설정과 렌더는 반영되지만 타임라인은 이름만 표시, 목록 선택은 cutSelection 미동기화.
- [x] 실패 테스트 확인: 오빗 선택 후 타임라인은 기존 이름만 표시되어 실패.
- [x] 최소 수정.
- [x] 신규 브라우저 검증과 기존 회귀 검증·빌드.
- [x] 생성·수정·백업·빌드 결과 파일 목록.

같은 카메라가 여러 컷에서 쓰이면 해당 카메라의 모든 컷 표시와 움직임이 함께 갱신된다.
시작 시점에는 이전과 같은 시작 구도가 보일 수 있다. 자동 재생이나 재생 위치 변경은 추가하지 않는다.
공개 배포와 기존 업로드 ZIP은 변경하지 않는다.

단계 자체 평가: 원인 확인 9/10, 구현 9/10. 최종 점수는 검증 후 기록.
