# SceneBlock v2.9.0 변경·검증 기록

작업 폴더는 2026-10-23-SceneBlock-v2.8.0이며 실행 버전은 v2.9.0입니다. 별도 SceneBlock Git 저장소와 공개 배포는 수정하지 않았습니다.

## 반영
- 기존 4개 모델 GLB 원본 보존. 어린이·청소년의 큰 머리 비율을 각각 82%, 90%로 완만하게 보정한 복제본 사용. 기본 키는 성인 175cm, 어린이 120cm, 청소년 155cm. 새로운 사실적 인물 모델 교체는 아닙니다.
- 캐릭터 sizeScale 0.25~2 저장·검증, 25~200% UI 및 초기화. 전신 비율·발밑 기준·동선 좌표 유지. 자세 고스트·회전 도구 크기 반영.
- 일반 소품 9종 / 탈것 7종 선택 분리. 자동차, SUV, 승합차, 버스, 트럭, 오토바이, 자전거는 외형과 규모를 잡는 절차적 프리비즈 소품입니다. 좌석·실내·탑승 자동 맞춤은 포함하지 않습니다.
- 동선 편집 진입 시 첫 걷기·달리기 구간 시작으로 이동. 경유점 번호·기존 경로 보존.
- 매뉴얼과 버전 표시 갱신. v2.8.3 카메라 수정 포함.

## 검증
- 신규 검사 실패를 먼저 확인한 뒤 수정. 전체 단위 테스트 138/138 통과.
- 신규 실제 Chrome 검사 6종: 나이별 키·바닥 접점, 전신 크기/Undo/Redo/초기화, 동선 1번 진입, 7종 추가/분류, 저장/열기, 영상 출력 통과.
- 기존 v28-camera 브라우저 회귀 11종 통과. 빌드와 배포 구성 검사 통과.
- 새 혼합 장면 WebM: VP8 1056x594, ffprobe 2.000초.
- dev/2026-10-24-backlog-verification에 재현 테스트, 전후 화면, 저장 프로젝트, 결과 JSON, 출력 영상 보관.
- 구현 자체평가 8/10, 검증·패키지 자체평가 9/10. 모델 비율 보정은 시각적인 개선이며 사용자의 최종 외형 평가는 남아 있습니다. 실제 AI 생성과 공개 배포는 이번에 검증하지 않았습니다.

## 업로드
기존 v2.8.3 저장소에는 changed-files ZIP의 내용 전체를 같은 경로로 반영합니다. 다른 버전이거나 확실하지 않으면 github-upload ZIP의 내용 전체를 저장소 루트에 사용합니다. node_modules/dist/dev는 업로드하지 않습니다.
