# SceneBlock v2.12.0 AI intent implementation plan

Goal: replace sample heuristics with explicit source-linked intent, capability report and deterministic draft compiler, preserving manual editing.
Approved design: ../2026-10-25-SceneBlock-AI-redesign-v1.0.0/2026-10-25-design.md.
Method: subagent-driven development; workspace is not the separate SceneBlock Git repository. No commits/push/install/deploy in this scope.

## Contract ruling
AI selects sourceIds from deterministic source units generated by buildSourceUnits(description). Engine computes UTF-16 start/end spans from original source, avoiding model counting offsets. Every source unit has a coverage record, including unsupported/unclassified. This preserves the approved source-span ledger without fragile AI offsets.

No implementation of handoff/exact gaze/clothing/weather; their requirements remain explicit unsupported until user waiver, never substituted action.

## Implementation rulings
- Entity DTO gained required requirementIds. Each binding kind must match the requirement kind, so an action cannot certify a requested shot or omitted table.
- Compiler capabilities intentionally expose a bounded supported subset; unsupported enums preserve the intention and block. Dynamic shots, articulated gaze, handoff and multiple independent movement paths are not implemented or substituted.
- Native intent request byte budget is64KiB to cover12000 Korean UTF16 prompt +8000 context, legacy routes remain32KiB.
- Existing heuristic modules became empty retired stubs so cumulative upload replaces their logic, with originals retained in backup. Sample-biased test assumptions replaced by explicit-intent and legacy-compatibility checks; old fixtures retained.
- Existing directing browser script was made current-tab aware; deprecated English option label/version assumptions removed. Its editing assertions remain.
- Implementation validation uses strict contract/provider mocks and browser fixtures. Planned live24 requests/provider, real installation and deployment remain separate unexecuted checks; this package must not be described as generally validated scene quality.

Completed scope: code/contract/compiler/UI/compatibility/local tests/native self-test/artifact packaging. Live AI, actual installation and public deployment remain explicitly unexecuted.
