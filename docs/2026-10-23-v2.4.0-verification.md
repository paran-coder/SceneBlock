# SceneBlock v2.4.0 검증

## 변경 범위
신규2026-10-23-SceneBlock-v2.4.0 폴더만 생성/수정. 이전버전·ZIP·SceneBlock 실제저장소·루트4문서 보존. 원격업로드/배포/모델다운로드 없음.

## 구현
선행협의: 기본clips위 actor.layers를 아래→위 순서로 합성. full/upper/leftArm/rightArm/head 마스크, 강도0–1, enabled, layer.clips+fadeIn/fadeOut. 이동은 기본clips에서만 계산. 같은레이어는 순차/다른레이어는 겹침허용. 반열린구간, 각fade최대클립절반, 마지막레이어우선. 기본골격 계산 후 대상 동작/포즈의 마스크만 quaternion slerp/position lerp. 상체뒤돌아보기는 모델Y기준회전, 골반/이동방향 유지. pose자산 export준비 포함.

카메라 인접컷의 경계드래그는 양측시간을 동시에 변경하고 바깥시간/최소.1초 보존. 초기이름/인라인이름변경, 구성시이름유지. 동일변경 이벤트 중복 발생 시 no-op기록을 쌓지 않아 Undo가 한 번에 복귀.
