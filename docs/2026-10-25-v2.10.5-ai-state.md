# SceneBlock v2.10.5 · AI 연결 표시 수정

## 변경
- 실제 연결과 AI 준비 상태를 구분해 버튼·요약을 함께 표시.
- 연결된 상태의 재연결 버튼 비활성화, 중복 프로그램 실행 차단.
- 프로그램 응답 / 사이트 승인 / AI 상태 확인별 실패 안내.
- PC 연결을 유지한 AI 상태 재확인, 해제·취소·재연결의 오래된 응답 무효화.
- 이전 세션의 401 응답이 새 세션 토큰을 지우지 않도록 보호.

## 검증
- 전체 자동 테스트 154개.
- AI 상태 브라우저 10종: 준비 완료·설정 재열기·AI 확인 실패/재시도·로그인/설치/CLI업데이트 필요·프로그램 응답 실패·사이트 승인 실패·호환성·인증 만료·취소/해제·확인 중 재연결·리스 만료.
- 기존 업데이트 안내 4종, 편집 도구/카메라 표시 6종.
- 빌드, 패키지 검사 및 누적 ZIP 적용 빌드 확인.
- 브라우저 AI 응답은 모의 응답. 실제 프로그램 실행·계정 로그인·AI 생성·배포는 미검증.

## 업로드
기존 파일 경로를 유지해 누적 수정 ZIP 내용을 GitHub에 업로드하거나 전체 업로드 ZIP을 사용합니다. 설치 프로그램은 v2.7.0 그대로입니다. 별도 SceneBlock 저장소와 기존 배포물은 수정하지 않았습니다.
