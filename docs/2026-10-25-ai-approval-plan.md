# 웹 AI 연결 승인창과 업데이트 안내 계획

사용자가 승인한 범위: SceneBlock 승인창의 한글·브랜드·버튼 통일, 기존 사용자 업데이트 안내, 설정 보존 확인.

- 웹 v2.10.4 / 연결 프로그램 v2.7.0. 기존 설치 v2.6.0과 기존 설치 파일 보존.
- 새 공용 WinForms UI를 승인창과 설치기에 적용. URL은 그대로 표시. 취소/X/Escape는 허용하지 않음. 연결 허용 후에만 기존 일회성 티켓 작성과 프로세스 기동.
- 웹에서 health 버전을 보관하고 명시적 버전 확인 및 구버전 업데이트 안내/다운로드/연결 해제 준비를 제공. 기존 호환 버전 사용은 강제로 막지 않음.
- 설치는 버전별 새 폴더, 기존 로그인/예전 파일 보존. URL 연결을 새 폴더로 전환하기 전 기존 명령 백업. 일회성 티켓/세션은 이관하지 않고 다시 승인.
- 이전 프로세스 사용 중에는 강제 종료하지 않고 모든 탭 연결 해제 후 약 90초 기다리도록 안내.
- 테스트는 작업 폴더 안의 별도 임시 설치 폴더와 UI 렌더링으로 수행. 사용자 PC의 실제 설치·프로토콜·로그인 정보는 바꾸지 않음.
- 전체 단위·브라우저 버전 안내 검사, 설치기 페이로드 검증 및 구버전 파일 보존 검사, 승인/취소 버튼 검사, 화면 렌더 확인 후 누적/전체 패키지 제공.

설계 자체 점검 9/10. 실제 계정 AI 생성과 모든 PC의 설치 성공은 이번 검증과 구분한다.
