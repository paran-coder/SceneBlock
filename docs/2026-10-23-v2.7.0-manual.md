# SceneBlock v2.7.0 사용 안내

## 동선 메뉴

상단 **동선 그리기**에 마우스를 올리거나 클릭하고 **직선 동선 / 곡선 동선**을 선택합니다. 키보드는 버튼에서 아래 화살표로 열 수 있습니다. 바닥 클릭으로 경유점을 추가하고 점을 끌어 수정합니다. 그리는 중에는 버튼 또는 Esc로 종료합니다.

## 정지 자세와 적용 부위

걷기·손 흔들기 같은 시간에 따라 움직이는 기능은 기본 동작/동작 레이어입니다. 정지 자세 라이브러리는 한 순간의 자세입니다. 걷기·달리기 이름의 라이브러리 항목도 애니메이션 재생이 아닙니다.

적용 부위를 먼저 선택하면 해당 부위에 권장되는 정지 자세만 보입니다. 그림의 초록색 부위가 실제 적용 범위입니다. **전체 정지 자세 보기**로121개 원본을 볼 수 있습니다. 원본 전신 자세 중 선택한 부위만 가져오며 부위 전용 모션을 생성하는 기능은 아닙니다.

## 시간별 목표 자세

1. 시간을 선택하고 부위와 정지 자세를 고른 뒤 **현재 시간에 자세 키 추가**를 누릅니다.
2. 타임라인에는 긴 유지 바 대신 다이아몬드 키를 표시합니다. 기본 동작 길이 밖이라도 장면 시간 안에서 추가할 수 있습니다.
3. 다른 시간에 다음 키를 추가합니다. 키 사이 자세를 보간하고, 이동은 기본 동작과 동선이 담당합니다.
4. 키 전후 기본값은 **기본 동작으로 복귀**입니다. 첫/마지막 키 앞뒤0.25초에 전환합니다. **첫·마지막 자세 유지**를 선택하면 유지합니다.
5. 편집 화면에 그 시간의 동선 위치에 반투명 인물과 시간 표시가 나타납니다. 인물 또는 키를 클릭해 이동하고, 키 드래그로 시간을 바꾸며 Delete로 선택 키를 삭제합니다. 실행 취소가 가능합니다.
6. 한 인물의 고스트는 최대32개 표시합니다. 영화 출력에는 고스트와 관절 표시가 포함되지 않습니다.
7. 다른 부위로 키를 추가하면 기존 부위의 키를 바꾸지 않고 새 목표 자세 레이어를 만듭니다. 같은 부위의 위쪽 레이어가 우선합니다.

기존 프로젝트의 포즈 키는 시간과 자세를 보존하고 **유지** 방식으로 불러옵니다. 새 키 트랙은 기본 동작 복귀가 기본입니다. 일정 구간 내내 자세를 유지하려면 별도의 **구간 유지 포즈 적용**을 사용합니다.

## 직접 관절 편집

1. 수정할 키의 시간을 선택하고 적용 부위를 확인합니다. **관절 선택 · 자세 편집**을 누릅니다.
2. 프리셋 없이 만들려면 **프리셋 없이 자세 만들기**를 누릅니다. 중립 T자 자세를 시작점으로 직접 조정합니다.
3. 인물이 확대됩니다. 노란 관절은 선택 부위, 회색 관절은 범위 밖입니다. 관절 점을 클릭하거나 관절 목록에서 고릅니다.
4. 선택한 관절 하나에만 로컬 회전축이 나타납니다. 팔꿈치·무릎은 굽힘 축을 사용합니다. 직접 드래그하거나 숫자를 입력합니다. 좌우 반전과 관절 초기화가 가능합니다.
5. **현재 시간 키에 저장**을 눌러 확정합니다. 저장 전에는 초안이며 편집 취소로 버릴 수 있습니다. 재생·시간 이동·다른 편집으로 넘어가도 초안은 취소됩니다. 저장 후 실행 취소가 가능합니다.

손발을 끌어 팔다리를 자동으로 맞추는 IK는 포함하지 않습니다. 기본 동작 위에 선택 부위의 정지 자세를 겹치고 보간하는 방식이며 자연스러운 보행·발 접지나 물리 제약을 자동 생성하지 않습니다.

인물 전체 방향 전환은 골반 높이의 수직 회전 도구로, 이동은 발밑 도구로 조작합니다. 관절 회전과 전체 인물 방향 전환은 별개입니다.

## 메인 화면과 AI 안내

왼쪽 위 SCENEBLOCK 로고는 현재 작업을 유지한 채 메인으로 이동합니다. 계속 편집·프로젝트 열기·새 장면을 선택할 수 있습니다. 저장하지 않은 변경이 있으면 새 장면 전에 확인합니다.

AI 설정1번은 SceneBlock 웹 연결 설치,2번은 별도의 Codex/Claude Code 설치·로그인입니다. 도구가 이미 설치되어 있으면 설치 명령만, 그 도구에 로그인되어 있으면 로그인 명령도 건너뜁니다. 웹사이트 로그인과 CLI 로그인은 별개입니다. v2.6.0 AI 연결 설치 기능은 그대로 호환되며 이미 설치했다면 재설치할 필요가 없습니다.
