# SceneBlock v2.6.0 검증

## 구현 및 자체 점검

- 참고 프로그램과 동일한 웹 시작 구조: 최초 EXE 설치, sceneblock URL 실행 등록, 로컬 사이트 승인, 숨김 실행, 일회용 승인 교환, 탭 임대/해제와 유휴 종료.
- 포트8768으로 참고 프로그램8766과 충돌 방지. 허용 Origin/Host, 일회성 256비트 nonce, 사이트에 묶인 토큰, 만료/다중 탭/취소 이후 늦은 응답 처리.
- Node24.14.1 실행 파일과 공식 전체 LICENSE를 설치 EXE에 포함. 설치기는 같은 버전의 다른 파일과 관련 없는 프로토콜 등록을 덮어쓰지 않음. 인지 가능한 이전 SceneBlock 등록은 확인 후 백업. 관리자·상주 서비스·시작 프로그램·모델 설치 없음.
- 설정은 설치·로그인 안내, 일상 작업은 왼쪽 연결/설명/구성/검토/적용. 구성안 미리보기 중 기존 장면 편집은 잠가 혼선을 방지.
- 직선·곡선 그리기, 굵은 동선 표시. 인물 기본 행 우선, 하위 레이어 들여쓰기. 실제 드래그로 인물 묶음/레이어 순서 변경. Delete로 선택 키/클립 삭제, Undo.

## 실행한 검사

- Node 테스트121개 통과. 승인 재사용·사이트 바꿔 쓰기 거부, 탭별 해제, 취소 후 늦은 승인 폐기, 유휴 자동 종료 포함.
- 실제 Chrome: 직선/곡선 가이드 정점 수와 데이터, 기본행/포즈 순서, 키/클립 Delete 및 Undo, HTML 드래그/드롭 인물 묶음·레이어 순서 변경 통과.
- 실제 Chrome + 실제 로컬 HTTP + 모의 AI 제공자: 프로토콜 호출 캡처 및 모의 OS 승인으로 일회용 승인 처리, 설정 닫은 상태의 왼쪽 연결·생성·동의·미리보기·버리기·적용·Undo 통과.
- 기존 v2.4 레이어 회귀11개(실제2초WebM와 ffprobe 포함), 포즈 적용 회귀5개, 1280/1600 화면의 동선 드래그·이전 시점 복귀 통과.
- Windows 설치 EXE 컴파일과 --verify-payload 검사 통과(설치·레지스트리 등록 없이 내장 파일 읽기만 수행).
- Windows PowerShell -ValidateOnly로 실제 프로토콜 주소 파싱 확인. Node에서도 주소 위조·nonce/Origin 검증.
- Vite 프로덕션 빌드와 정적 배포 구성 검사 통과. 배포 폴더와 작업본 해시 일치 검사, 비공개 실행 상태/로그/캐시 제외.

## 검증의 한계

이 PC에는 설치하거나 프로토콜을 등록하지 않았습니다. 새 PC에서 EXE 실행 → 실제 브라우저 앱 열기 → Windows 승인 → 공개 HTTPS 로컬 네트워크 권한 흐름 전체는 미검증입니다. 브라우저 테스트의 OS 승인만 모의이며 HTTP 인증과 UI는 실제 실행했습니다. 본인 계정으로 실제 AI 생성은 하지 않았습니다. 원격 GitHub/Vercel 업로드·배포는 하지 않았습니다. Windows x64 서명되지 않은 베타 설치기입니다.

## 단계 평가

연결 인증/수명9/10, 편집 UI9/10, 로컬 통합 및 패키지9/10. 남은 검증은 새 PC 설치·공개 HTTPS·실제 제공자 응답입니다. 이전 버전·원본 저장소·참고 폴더·작업 최상위4문서는 보존했습니다. 모델 가중치를 다운로드하지 않았습니다.
