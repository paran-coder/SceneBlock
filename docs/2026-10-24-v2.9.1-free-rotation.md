# SceneBlock v2.9.1 세 축 회전

인물과 소품의 회전 도구를 누르면 바로 X/Y/Z 회전구가 표시됩니다. 추가 모드 선택은 없습니다. 숫자 각도 입력도 세 축을 지원합니다.

## 구현
기존에는 X/Z 표시를 끄고, 변환 완료 콜백에서 rotation.y만 전달했으며 저장값도 Y축 하나였습니다. 선택·드래그·평가·고스트·파일 저장 전 과정을 수정했습니다.
기존 rotation 숫자는 Y축 방향으로 유지하고 선택 필드 rotation3D=[X,Y,Z]를 추가했습니다. 기존 파일의 방향을 보존하며 동선 자동 바라보기는 Y축만 계산합니다. 인물 수동 회전 시 자동 바라보기를 해제합니다.
인물은 크기·모델 키를 반영한 골반 높이를 중심으로 기울어집니다. 회전 중 발밑 원점과 동선 위치가 함께 이동해 중심을 고정합니다. 소품은 기존 소품 원점을 사용합니다.

## 검증
- 단위 테스트 141/141 통과. 잘못된 세 축 값 거부, JSON 왕복, 크기 변경 인물의 골반 중심 불변 검사 포함.
- 신규 Chrome 검사 4종 통과: 인물/소품 실제 회전구 마우스 드래그와 기울기 확인, 숫자 입력·Undo/Redo, 실제 저장/열기, 영상 출력.
- v28 브라우저 회귀 9종, 관절 편집 통합 회귀 8종 통과.
- 빌드/배포 구성 검사 통과. 기울어진 인물·소품을 포함한 실제 WebM 출력과 ffprobe 2.000초 확인.
- 증거: dev/2026-10-24-rotation-verification. 백업: dev/2026-10-24-rotation-v2.9.0-backup.
