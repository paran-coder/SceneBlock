# SceneBlock v2.8.0 사용 안내

## 자세 편집
1. 인물과 시간을 선택하고 적용 부위를 고릅니다.
2. **현재 자세에서 관절 편집**은 화면의 현재 자세로 시작합니다. **중립 자세에서 새로 만들기**는 프리셋 선택 없이 T자세에서 시작합니다.
3. 부위 안의 관절이 자동 선택됩니다. 관절 점 또는 목록으로 바꾸고 회전축이나 각도 입력으로 조정합니다. 부위와 목록 필터를 바꿔도 편집 초안은 유지됩니다.
4. **편집한 자세 저장**을 누르면 편집을 시작한 시간에 키를 저장합니다. 편집 취소는 초안을 버립니다. 편집 중에는 시간 이동·재생 대신 먼저 저장 또는 취소하세요.
5. 프리셋을 바로 찍으려면 **선택 프리셋을 현재 시간에 기록**을 사용합니다. 직접 편집 중에는 이 버튼을 숨겨 저장 역할을 구분합니다.
6. 구간 전체에 유지하려면 **구간 적용 · 고급**을 펼칩니다. 구간 유지 포즈는 레이어에, 정지 포즈는 기본 동작 구간에 적용됩니다.
7. 타임라인의 다이아몬드는 시간별 자세 키입니다. 키 사이에서 자세가 연결되고 전후 기본 동작 복귀/유지를 정할 수 있습니다. 마지막 키를 삭제하면 빈 레이어도 사라집니다. Undo로 복구할 수 있습니다.

오른쪽 ‘편집 대상’ 표시가 현재 인물·레이어입니다. 시간 이동만으로 선택한 행동이 바뀌지 않습니다. 타임라인 클립을 직접 선택해 바꿉니다.

## 이동과 회전
동선 그리기에 마우스를 올려 직선/곡선을 고릅니다. 점 드래그로 수정하고 Esc로 종료합니다. 위에서 보기 버튼은 이전 시점으로 돌아갈 수 있습니다. 우클릭 이동, Space 재생/정지를 유지합니다.
전체 인물 회전은 몸통/골반 높이의 Y축, 이동은 발밑입니다. 직접 회전값을 바꾸면 ‘동선 방향으로 바라보기’를 끕니다. 경로를 따라 바라보려면 다시 켭니다. 소품 회전은 Y축만 지원합니다.

## 저장과 복구
프로젝트 저장은 파일로 보관하는 기능입니다. 미저장 상태로 새로고침/이탈하면 브라우저가 경고할 수 있습니다. 다시 접속했을 때 복구 안내에서 작업을 복구하거나 버립니다. 복구본은 현재 브라우저·사이트 주소의 로컬 저장소에 하나 보관됩니다. 브라우저 데이터 삭제 시 사라지므로 프로젝트 파일 저장을 대신하지 않습니다.

## AI 준비
왼쪽의 AI 연결·설정 버튼 하나에서 안내합니다. 1단계 SceneBlock 연결 기능 설치와 2단계 Codex/Claude Code 설치는 별도입니다. 선택한 공식 도구가 이미 설치됐다면 설치 명령만 건너뛰고, 그 도구에 로그인까지 했다면 로그인 명령도 건너뜁니다. 웹사이트 로그인만으로 CLI 로그인이 되는 것은 아닙니다.
준비 후 설정창을 닫고 평소처럼 왼쪽 장면 설명과 장면 구성 버튼을 사용합니다. 구독 인증·한도는 사용하는 도구에 따르며 실제 계정 연결은 사용자 환경에서 확인해야 합니다.
