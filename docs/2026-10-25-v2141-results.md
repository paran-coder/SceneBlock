# SceneBlock v2.14.1 · 포즈블럭 가져오기 제거

사용자의 명시적 요청으로 외부 PoseBlock JSON 가져오기 UI·변환·렌더링을 제거했습니다. 모듈 2개와 전용 테스트 2개를 삭제하고 관련 설명과 스타일을 정리했습니다. sample 원본/기존 ZIP/독립 SceneBlock Git은 보존했습니다. 기존 포즈 라이브러리·직접 관절 편집·카메라·UI 도움말 개선은 유지합니다.

v2.14.0에서 외부 포즈를 가져와 저장한 프로젝트는 제거된 데이터가 있다는 안내와 함께 열기를 중단합니다. 잘못된 자세를 조용히 보여주거나 원본 파일을 바꾸지 않습니다. 필요하면 보존된 v2.14.0에서 가져온 포즈 레이어를 삭제한 후 저장해 다시 열 수 있습니다.
