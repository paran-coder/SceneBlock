# SceneBlock v2.14.1 사용 안내

포즈블럭 JSON 가져오기는 v2.14.1에서 제거했습니다. 기본 포즈 라이브러리와 직접 관절 편집을 사용하세요.

## 카메라
왼쪽 + 카메라 추가 → 카메라 시점에서 마우스로 구도 조정 → 현재 시간에 구도 기록 → 타임라인에 촬영 구간 추가. 카메라는 생성 즉시 미배치 행으로 나타나며, 이 행의 버튼으로도 촬영 구간을 지정할 수 있습니다. 겹치는 기존 컷이 있으면 교체할 구간과 확인 체크가 표시됩니다. 해당 시간 밖의 컷은 유지됩니다. 카메라 생성만으로 기존 컷을 덮어쓰지 않습니다.

기존 장면 편집 시점은 새 카메라의 초기 구도로 사용합니다. 이후 카메라 이동·회전 도구 또는 이 카메라 시점으로 편집으로 구도를 조절합니다. 카메라 시점 편집에서 휠/드래그를 마치면 초안이 생기며 구도 기록 또는 취소가 필요합니다. 자신이 보고 있는 카메라 형상은 시점을 가리지 않도록 숨깁니다. 다른 요소를 선택하거나 기록/취소하면 시점 편집을 종료합니다.

## 편집 공간과 도움말
설정 항목 옆 ?는 클릭으로 열고 다시 클릭·Esc·바깥 클릭으로 닫습니다. 상태·오류·전송 동의·편집 중 안내는 계속 표시합니다. 하단 장면 요소/연출 설정 버튼으로 좌우 패널을 접고, 타임라인 높이 슬라이더로 중앙 화면과 트랙 공간을 조절합니다. 작은 화면에서는 패널이 겹쳐 열립니다.

장면 요소를 이름/종류로 검색하고 인물 트랙의 화살표로 하위 레이어를 접을 수 있습니다. 중앙 상태줄에서 대상·시간·편집 모드를 확인하고 구도 기록/자세 저장/그리기 완료를 실행합니다. W는 이동, E는 회전입니다. 입력·팝업·관절/동선/카메라 초안 편집 중에는 단축키가 도구를 바꾸지 않습니다. 배우/소품의 기존 XYZ 회전은 유지합니다.

변경 없음은 현재 메모리 상태와 저장 기준의 차이가 없다는 뜻입니다. 브라우저 복구본은 프로젝트 파일 저장을 대신하지 않습니다. 중요한 작업은 프로젝트 저장으로 보관하세요.

## 영상 출력
영상 내보내기를 누르면 실제 캔버스 해상도·FPS·길이·WebM(VP8)·영상 전용 여부를 먼저 보여줍니다. 내보내기 시작 후 취소할 수 있으며 기존 편집 상태로 돌아갑니다. 저장창에서 파일명과 위치를 선택합니다. 브라우저가 저장창을 지원하지 않으면 다운로드 방식으로 저장합니다. 네이티브 저장창이 이미 열렸다면 저장창 자체도 닫아주세요.

이번 수정은 웹 v2.14.1입니다. 연결기 v2.10.3은 변경하지 않았고 실제 설치·로그인·배포를 실행하지 않았습니다.
