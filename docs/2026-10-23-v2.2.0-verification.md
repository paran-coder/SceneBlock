# SceneBlock v2.2.0 일괄 수정 검증

사용자가 합의한 항목을 '일단 여기까지만 적용해봐'로 승인한 범위에서 새 버전 폴더에 적용했습니다. 기존 Git 저장소·이전 버전 폴더·ZIP은 편집하지 않았습니다. 원격 GitHub/Vercel 변경과 모델 다운로드는 없습니다.

## 구현 결과

- 슬라이더 손잡이 중심과 초 눈금/모든 트랙의 시작·끝을 동일한 그리드로 정렬. 트랙 스크롤바의 실제 너비도 반영.
- 재생선, 초 눈금, 선택 클립 강조, 이동·트림 중 시간 배지, 인물/행동 및 카메라 선택 동기화. 행동 변경·삭제는 인스펙터 연결.
- 새 인물은 고정 팔레트에서 구분되는 색상을 배정하며, 이름 입력란에 포커스·전체 선택. 인물별로 재질을 복제해 3D/목록/트랙 색상이 서로 독립적으로 적용됨.
- 공식 포즈 121개의 한글 이름·분류와 한영 혼합 검색. 원본 ID는 변경하지 않음.
- 의자·벤치·소파·문·창문·계단 추가, 기존 3종 포함 총9종. 기본 형상의 크기/회전/색상 편집 및 JSON 저장 지원.
- Space 재생/정지와 우클릭 화면 이동 유지. 타임라인에 키보드 포커스가 있을 때에도 Space는 재생/정지로 처리.
- 기존 동선 점 드래그·위에서 보기 복귀·포즈 목록 겹침 수정 유지. 선택형 로컬 엔진 소스 다운로드의 정적 URL도 확인.

## 실제 검사

- 단위 테스트 57/57 통과. 신규 팔레트/이름, 포즈 번역·검색·ID 보존, 소품 형상·크기·검증, 재질 독립성과 자원 해제 포함.
- 일괄 변경 Chrome 검사 7개 흐름 통과: 1280×720 및 1600×1000 시간축/재생선 정렬, 인물4명으로 세로 스크롤 발생 후 동일 정렬, 이름 포커스/전체 선택/변경, 3D·목록·트랙 색상 일치, 선택/트림/시간 배지/행동 변경·삭제/카메라 선택, 한영 포즈 검색과 원본 ID, 소품6종 추가/색상, Space/우클릭, 새 프로젝트 실제 다운로드·파일 복원.
- 기존 연출 Chrome 검사 10개 흐름 통과: 동선 클릭/드래그/Undo, 이전 시점 복귀, 포즈와 관절 보정, 카메라, 예제, 저장 복원, 영상 출력 등.
- 기존 동선 패치 Chrome 검사 2개 화면 크기 통과: 경사 시점에서 12px 벗어난 점 드래그, 그리기 완료 후 이동, 이전 시점 복귀.
- WebM 영상: VP8 1056×594, 1초/30프레임 디코딩 확인. 기본 검사에서 외부/로컬 엔진 요청 없음, JavaScript 페이지 오류 없음.
- production build 및 정적 패키지 검사 통과. 보안 헤더는 vercel.json과 같은 로컬 검사 서버에 적용함.

## 한계와 평가

이는 정적 웹 프리비즈 도구의 편집 기능 보완입니다. Kimodo 새 모델 설치·생성 제약 전달·GPU 추론, 실제 배포 HTTPS→로컬 연결은 이번에 검증하지 않았습니다. 기본 동작의 자연스러움, IK/행동 블렌딩, 자동 충돌 검사는 기존 제한을 유지합니다. 한글은 원본 121개 포즈 이름을 사람이 이해하기 쉽게 번역한 표시값이며 자산 ID와 프로젝트 데이터는 유지합니다.

독립 구현 검토: 포즈 의미와 좌우 관계, 재질 복제/자원 해제, 타임라인 선택·취소·스크롤·키보드 동작 확인. 계산/데이터 9/10, UI 직접 조작 9/10, 배포 준비 9/10. 이 버전의 공개 사이트 재배포는 사용자 작업으로 남습니다.

최종 배포 준비 검사: 업로드 소스의 별도 복사본에서 npm ci --offline → build → 57개 단위 테스트 → 정적 패키지 검사 모두 통과했습니다. 개발용 dist에 누적된 과거 번들은 ZIP에 포함하지 않았고, 새 배포에서 생성되는 dist를 기준으로 검사했습니다. 누적 패치는 v2.1.x에 필요한 신규 모듈과 갱신된 스타일도 포함합니다.
