# SceneBlock v2.1.0 화면 연결 변경안

신규 버전 폴더 안의 복사본만 변경한다. 기존 SceneBlock Git 저장소, 기존 업로드 폴더/ZIP, 루트 4개 문서는 수정하지 않는다. 자동 승인 검토가 기존 테스트 파일 덮어쓰기를 사용자 사전 확인 지침 위반으로 차단하여 해당 범위의 수정 승인을 요청했다.

## 대상과 변경 내용

- src/2026-10-23-app.mjs: 신규 directing UI import/install, 저장 형식의 기존 행동을 clips로 변환, inspector/타임라인 렌더 연결, SceneBlock 이름과 v2.1.0 표시, Undo/Redo와 프로젝트 교체 시 동선 종료, 장면 단축 시 clips 정리, 인물 삭제 시 camera follow 참조 정리, 예제/생성 모션을 선택 행동에 적용, export 전 자산 준비 대기.
- src/2026-10-23-directing-ui.mjs: 신규 파일의 통합 검토에서 발견한 stale actor 참조, 재생 중 동선 편집, 클립 수 제한, 속도를 반영한 모션 구간 길이, 타임라인 선택/오류 복원 보완.
- src/2026-10-23-stage.mjs: 라이브러리 포즈는 기본 동작과 겹쳐 적용하지 않고 바인드 자세에서 직접 적용. offsets만 마지막 적용.
- src/2026-10-23-style.css: 경로 툴바, 경유점 목록, 행동 목록, 타임라인 이동/양끝 트림 핸들 스타일.
- index.html/package.json/package-lock.json: SceneBlock/v2.1.0 메타데이터와 새 통합 검사 명령. 기존 잠금 의존성 유지.
- tests/2026-10-23-directing.e2e.mjs 및 기존 브라우저 테스트: 로드 진단 문자열 갱신, 실제 포인터 동선/핸들 이동/클립 조정/저장복원/영상 검증.
- README.md 및 새 버전 문서: 구현 결과와 남은 AI 제약 연결 한계를 분리해 기록. 새 배포 ZIP과 파일 manifest 작성.

## 현재 상태

단위 검사 36/36 통과: 기존 24개 + 행동/카메라 7개 + 포즈 5개. 새 화면 모듈은 아직 기존 app에 연결하지 않았으므로 사용자용 완성본이나 배포 가능 상태라고 주장하지 않는다. 독립 검토로 위 결함을 찾았고 승인 후 같은 새 버전 폴더 안에서 수정한다.

자체 평가: 데이터/계산 9/10, 포즈 변환 단위 검증 9/10, 3D 화면 8/10(실브라우저 미검증), 통합은 진행 중. 새 모델 다운로드 및 새 추론은 수행하지 않음.

후속 기록: 사용자가 새 버전 폴더 안의 수정을 명시적으로 승인했습니다. 위 변경과 검토 수정은 적용·검증 완료했습니다. 현재 결과는 v2.1.0 검증 기록을 기준으로 확인하세요.
