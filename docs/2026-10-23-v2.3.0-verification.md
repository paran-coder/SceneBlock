# SceneBlock v2.3.0 검증 기록

## 범위와 보존
승인한 카메라 컷/행동 시간/동선 표시/카메라 움직임/툴바 일괄 개선. 2026-10-23-SceneBlock-v2.3.0 안에서만 생성·수정. 원본 SceneBlock 저장소, 이전 버전과 ZIP, 루트 메모 문서는 보존. GitHub 접근·업로드와 Vercel 배포, 모델 다운로드는 하지 않음.

## 원인과 해결
- Stage는 편집 카메라와 촬영 카메라를 따로 렌더링하나 카메라 선택은 설정만 선택했음. 컷 클릭은 시간 이동+촬영 모드, 활성 샷 이름 표시. 미배치 카메라는 임시 미리보기이며 출력 때 해제/종료 후 복원.
- evaluateActor가 actor.start/end로 이동하고 clips로 포즈만 계산했음. 걷기/달리기 구간 누적 시간을 전체 동선 진행률로 사용. 정지/빈 구간은 위치 유지. 레거시 clips 미지정은 기존 계산 보존.
- 선택 인물의 경로를 항상 그리던 refreshPathGuide를 명시적 편집 중만 표시. 카메라 경로도 동일 가이드/드래그, 높이 평면과 XYZ 편집 지원.
- 카메라 평가와 설정에 13운용. 새 유형 기본값 명시 저장, 예전 문서의 누락값은 기존 계산과 일치하는 표시. 거리 지정 시 이전 endPosition보다 우선. 전진은 타깃 0.05 앞에서 제한.
