# SceneBlock v2.10.3 — 도구 선택 표시와 중앙 카메라 표시 토글

## 반영
- 실제 붙어 있는 전체 대상 조절 도구를 기준으로 이동/회전 버튼을 상호 배타적으로 강조하고 체크 및 aria-pressed 표시. 인물·소품·카메라에 적용. 대상/탭/프로젝트 갱신 후 동기화.
- 동선/관절 편집, 촬영 모드, 숨긴 카메라처럼 전체 대상 조절기가 없을 때 해당 버튼 강조를 해제.
- 상단 카메라 표시 토글: 편집 장면의 카메라 몸체·이름표·촬영 범위·카메라 조절기 표시/숨김. 숨긴 카메라는 레이캐스트 대상에서도 제외.
- 작은 실제 카메라 뷰어와 목록은 유지. 목록에서 카메라 선택 또는 촬영/편집 화면 전환 시 숨김 선택 유지. 숨김 중 중앙 이동·회전·동선 그리기는 안내 후 실행하지 않음.
- 카메라 동선 그리기 도중 숨기면 그리기 종료. 초안 중 표시 토글을 허용하고 초안 보존. 표시 설정은 현재 세션의 편집 옵션이며 프로젝트 JSON에는 저장하지 않음.

## 검증
- 새 브라우저 검사에서 기존 이동 도구 aria-pressed 누락을 먼저 재현.
- 전체 자동 테스트 147/147 통과.
- 신규 실제 Chrome 6개 묶음: 인물/소품 선택 표시와 재렌더, 동선/관절 전환, 카메라 도구 및 숨김/뷰어 유지, 숨긴 카메라 실제 클릭 제외/목록 선택 유지/안내, 카메라 경로 종료와 화면 전환 유지, 초안 보존/1280px 배치.
- 기존 카메라 통합 9개, 초안 보호 10개, 이름표/설정 분리 5개, 자유 회전 4개 통과. 총 브라우저 34개 항목 통과, 페이지 오류 없음.
- 실제 카메라 경로 영상 5초 출력 검증. 빌드 및 패키지 검사.
- 새 결과/스크린샷: dev/2026-10-24-tool-state-verification. 원본 백업: dev/2026-10-24-tool-state-v2.10.2-backup.
- 자체 점검 구현 9/10, 최종 검증 9/10. 실제 AI 생성과 공개 사이트 배포는 수행하지 않음.
