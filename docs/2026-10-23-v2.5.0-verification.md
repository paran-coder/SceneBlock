# SceneBlock v2.5.0 검증 기록

## 완료 범위

인물·카메라 곡선 동선, 레이어 포즈 키프레임·관절 보간·다이아몬드 드래그, 포즈 버튼 크기/간격, 상단 촬영 표시, Codex/Claude 공식 CLI 선택 연결과 안내, 생성 구성안 검토·적용·실행 취소.

## 직접 확인한 결과

- Node 자동 테스트 114개 통과. 프로세스 취소·시간/출력 제한·Origin/Host·인증·임시 경로 경계 포함.
- Vite 프로덕션 빌드 및 정적 배포 구성 검사 통과.
- 실제 Chrome 브라우저: 버튼 크기/간격, 촬영 표시 정렬, 포즈 키 두 개 기록, 서로 다른 관절 자세/중간 보간, 결정적 재탐색, 키프레임 드래그/Undo, 저장/불러오기 통과.
- 실제 Chrome + 로컬 HTTP 연결 프로그램 + 모의 AI 제공자: 연결/상태 확인, 전송 동의, 구성안 검토/버리기/적용/Undo 통과. 연결만으로 생성하지 않음 확인.
- 기존 레이어·타임라인·카메라 컷·프로젝트 저장 회귀 11개 시나리오와 포즈 적용 회귀 5개 시나리오 통과.
- 실제 2초 WebM 내보내기와 ffprobe 길이 확인 통과.
- 설치된 공식 CLI의 읽기 전용 상태 확인: Codex 0.149.1, Claude Code 2.1.283 모두 설치/로그인/구독 인증 감지.

## 검증하지 않은 범위

실제 계정으로 AI 장면 생성은 실행하지 않았습니다. 생성 흐름은 모의 제공자로 확인했습니다. 원격 GitHub 업로드, Vercel 배포 및 HTTPS 사이트에서의 실제 로컬 네트워크 권한 요청은 미검증입니다. 브라우저·OS 설정에 따라 로컬 접근 승인이 필요할 수 있습니다.

## 자체 점검

구현·브라우저 검증 9/10. 실제 계정 생성과 원격 배포 검증을 남겨둡니다. 이전 버전, 기존 ZIP과 SceneBlock 저장소는 수정하지 않았습니다. 모델 가중치는 다운로드하지 않았습니다.
