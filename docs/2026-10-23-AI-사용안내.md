# SceneBlock v2.5.0 AI 연결 안내

기본 장면 편집은 웹주소로 접속해 바로 사용합니다. AI 연결은 선택 기능입니다. 일반 ChatGPT/Claude 웹페이지의 로그인 상태를 직접 가져오지 않습니다.

## 처음 한 번

1. 앱의 **AI로 장면 구성 · 연결 안내**를 엽니다. 사용할 Codex 또는 Claude Code를 고릅니다.
2. Node.js 22 이상을 공식 사이트에서 설치합니다. 선택한 AI의 설치 명령을 복사해 PowerShell에서 실행하고 공식 로그인 명령으로 본인 계정에 로그인합니다. 앱에는 비밀번호·AI 인증키를 입력하지 않습니다.
3. 앱에서 연결 프로그램 ZIP을 내려받아 압축을 풀고 `2026-10-23-launch.cmd`를 실행합니다. 설치 후 이미 열어둔 연결 프로그램이 있으면 다시 켭니다.
4. 연결 프로그램 창을 열어두고 그 창에 나온 6자리 코드를 앱에 입력합니다. 이 코드는 AI 로그인 비밀번호가 아닙니다. **연결 및 상태 확인**을 누릅니다.
5. 준비 완료를 확인하고 장면 설명을 입력합니다. 전송 동의 후 **AI 구성안 만들기**를 누릅니다. 연결만으로 AI 생성이나 결제를 실행하지 않습니다.
6. 구성안의 시간 슬라이더로 뒤의 3D 화면을 확인한 후 **현재 장면에 적용** 또는 **구성안 버리기**를 선택합니다. 적용 후 실행 취소가 가능합니다.

## 다음 사용

연결 프로그램을 실행하고 새 6자리 코드로 연결합니다. 설치·로그인은 유지된다면 반복하지 않습니다. 연결 프로그램을 꺼도 기본 웹 편집은 계속 가능합니다. 브라우저 새로 고침 후에는 다시 연결합니다.

## 상태별 해결

- 연결 실패: 프로그램 창이 열려 있는지, Node.js 설치 여부, 브라우저의 로컬 네트워크 접근 허용을 확인합니다. 배포 사이트는 https://scene-block.vercel.app 만 허용합니다.
- 코드 불일치: 지금 열려 있는 프로그램 창의 코드를 입력합니다. 5회 실패하면 1분 기다립니다.
- 설치 필요: 선택한 공식 CLI를 설치한 뒤 연결 프로그램을 다시 실행합니다.
- 로그인 필요: 선택한 공식 로그인 명령을 실행한 뒤 **설치·로그인 다시 확인**을 누릅니다.
- 업데이트 필요: 공식 CLI를 업데이트하고 다시 실행합니다.
- 사용 한도: 본인 AI 요금제의 한도를 확인합니다. 구독 인증과 API 인증은 다르며, API 인증 감지 시 별도 요금 가능성을 앱에 표시합니다.
- 생성 실패: 기존 장면은 유지됩니다. 설명을 줄이거나 지원되는 행동·소품으로 다시 요청합니다.

AI에 보내는 내용은 입력한 설명과 현재 장면의 인물·소품·카메라 요약입니다. 영상·이미지·Kimodo 모션 파일은 보내지 않습니다. AI는 지원되는 기능으로 편집 가능한 구성안을 만들며 새 인체 동작을 생성하는 모델은 아닙니다.

로그인 정보는 공식 CLI가 관리합니다. SceneBlock은 공식 CLI를 실행하며 비밀번호나 구독 인증 토큰을 추출하지 않습니다. 로컬 연결 토큰은 브라우저 메모리에만 보관합니다. 사용량·데이터 처리는 해당 서비스의 계정 설정과 정책을 따릅니다.
