# SceneBlock v2.6.0 AI 연결·사용 안내

기본 편집은 웹주소에서 바로 사용합니다. AI는 선택 기능이며 설치·로그인 설정과 평소 장면 작업을 나눕니다.

## 처음 한 번 준비

1. 왼쪽 **AI 연결 · 설정**을 엽니다. 사용할 Codex 또는 Claude Code를 고릅니다.
2. **Windows AI 설치 프로그램 다운로드**를 누르고, 브라우저 다운로드 목록에서 받은 EXE를 엽니다. 설치 창의 **설치 / 연결 복구**를 누르고 표시된 설치 위치·웹 실행 등록 내용을 확인합니다. 단순 다운로드만으로 설치되지는 않습니다.
3. 설정에 표시된 공식 AI 설치 명령을 PowerShell에서 실행합니다. 이미 설치했다면 건너뜁니다. 로그인 명령을 실행하고 공식 브라우저 화면에서 본인 계정으로 로그인합니다. 이미 로그인되어 있으면 반복하지 않습니다.
4. 설정의 **AI 연결**을 누릅니다. 브라우저 앱 열기와 로컬 사이트 승인 창에서 SceneBlock 주소를 확인해 허용합니다. 로컬 네트워크 접근을 물으면 허용합니다.
5. 설치·로그인 상태가 준비되면 설정을 닫습니다. ZIP 해제, CMD 유지, 6자리 코드 입력은 필요 없습니다. 연결 프로그램 실행 환경도 설치 EXE에 포함됩니다.

## 평소 장면 구성

1. 웹사이트를 열고 왼쪽 구성 방식에서 **ChatGPT Codex** 또는 **Claude Code**를 고릅니다.
2. **AI 연결**을 누르고 필요한 앱 열기·사이트 사용을 승인합니다. 설정 창을 계속 띄울 필요가 없습니다.
3. 같은 왼쪽 **장면 설명**에 원하는 장면을 입력합니다.
4. AI로 보낼 정보에 동의한 뒤 **장면 구성**을 누릅니다. 연결만으로 AI 생성은 시작하지 않습니다.
5. 구성안이 나오면 왼쪽 미리보기 시간과 3D 화면을 확인합니다. **현재 장면에 적용** 또는 **구성안 버리기**를 선택합니다. 적용한 결과는 직접 편집하거나 실행 취소할 수 있습니다.
6. 설치 없는 기존 방식은 **로컬 규칙**을 선택합니다.

## 문제 해결

- 앱을 찾을 수 없음: 첫 설치 EXE를 다운로드 목록에서 실제로 열었는지 확인합니다. 설치했다면 같은 설치기의 연결 복구를 사용합니다.
- 로컬 연결 실패: 앱 열기·사이트 승인·브라우저 로컬 네트워크 권한을 확인합니다. 오류만으로 미설치라고 판단하지 않습니다. 기다리는 중에는 **연결 대기 취소**가 가능합니다.
- 설치/로그인/업데이트 필요: AI 연결·설정에서 해당 공식 명령을 실행하고 **설치·로그인 다시 확인**을 누릅니다.
- 다른 프로그램이 포트 사용: 기존 프로그램은 종료하지 않습니다. SceneBlock은8768, 참고 음성 프로그램은8766을 사용합니다.
- 다른 웹 도메인: 기본 승인 주소는 https://scene-block.vercel.app 입니다. 다른 배포 주소는 개발자가 허용 주소를 수정하고 설치기를 다시 빌드해야 합니다.
- 사용 한도: 본인 AI 요금제를 확인합니다. API 인증이면 별도 API 요금 가능성을 앱에 표시합니다. 구독도 사용 한도가 있습니다.

## 설치와 데이터

Windows x64용 서명되지 않은 베타 설치기입니다. 현재 사용자 LocalAppData/SceneBlock/AI/2.6.0에 설치하고 sceneblock 실행 주소를 등록합니다. 관리자 권한·시작 프로그램·상주 서비스·AI 모델 설치를 요구하지 않습니다. Node 실행 환경과 라이선스가 포함됩니다. 기존 Codex/Claude 로그인 설정을 변경하지 않습니다. 웹 탭과 작업이 없으면 연결 기능은 자동 종료합니다.

장면 설명과 인물·소품·카메라 요약만 선택한 AI로 보냅니다. 영상·이미지·Kimodo 모션 파일은 보내지 않습니다. 로그인 정보는 공식 CLI가 관리하고 SceneBlock은 구독 인증 토큰을 추출하지 않습니다. AI는 현재 지원되는 기능으로 편집 가능한 구성안을 만들며 새로운 인체 동작 생성 모델은 아닙니다.

실제 새 PC 설치·공개 HTTPS 브라우저 권한·본인 계정 AI 생성은 이번 개발 검증에서 실행하지 않았습니다.
