# SceneBlock v2.10.0 카메라 구도 편집과 오른쪽 탭

## 반영 범위
- 큰 장면 편집 화면에 카메라 몸체/렌즈/손잡이 형태와 선택 카메라 촬영 범위. 이동/회전 고리로 조작. 화면 밖 카메라는 위치 보기로 확인.
- 왼쪽 아래 별도 실제 WebGL 촬영 뷰어. 이름/시간/화각, 크기 3단계, 접기. 미니 뷰어 자체의 마우스 카메라 조작은 제공하지 않으며 큰 화면 조작/편집 시점 가져오기를 사용합니다.
- 현재 시간 구도 기록: camera.keys에 id/time/position/target/fov/roll 저장. 절대 시간 기준, 같은 시간 기록은 교체. 구도 사이 선형/완만한 전환과 직선/곡선 경로, 기울기 최단 회전. 타임라인 별도 ◆ 행.
- 카메라 경로와 기록의 위치 공유. 경유점 Y 높이 조절, 점 추가/삭제 시 현재 컷 범위에 기록 시간을 재배치. 현재 카메라가 여러 컷에 사용되면 각 컷에 별도 키를 두려면 해당 절대 시간에 기록합니다.
- 기록이 있으면 기존 프리셋보다 우선하며 중복 합성하지 않습니다. 프리셋 파라미터를 기록으로 자동 변환하는 기능은 추가하지 않았습니다. 명시적 전체 기록 삭제로 프리셋에 복귀합니다.
- 오른쪽 기본 설정/인물 연출 또는 기본 설정/카메라 연출. 인물 동선/행동, 라이브러리, 시간별 자세를 접기 그룹으로 구분. 기존 왼쪽 목록/추가 영역 유지. 탭·펼침 상태 유지, 키 클릭 시 관련 연출 탭 열기.
- 카메라 초안은 기록/취소 전 시간 이동/재생/저장/내보내기/대상 전환을 막고 브라우저 이탈 경고. 아직 기록하지 않은 초안은 프로젝트 복구본에 포함되지 않습니다.
- 카메라/가이드/관절 고스트는 미니 촬영 뷰어와 영상 출력에 표시하지 않음.
