# FRAME Previs Web v2.0.0 — 웹 전환 설계·계획

사용자 지시: 웹 주소로 접속하게 변경, 사용자가 GitHub에 올리고 Vercel에서 배포할 예정. 계속 진행 승인.

## 결과물
독립 새 폴더에 Vite 정적 웹앱과 소스 전용 GitHub 업로드 폴더를 만든다. 기존 데스크톱 두 버전 및 루트 문서4개는 보존한다. 원격 업로드·배포는 하지 않는다.

## 기본 기능
Electron/CMD/Python 없이 브라우저의 Three.js/WebGL로 편집·재생·카메라·사전 생성 예제·파일 저장복원·WebCodecs 영상 내보내기. 파일 선택기는 사용자 PC에 저장하며 서버로 장면을 업로드하지 않는다. 파일 시스템 API 미지원/사용자 활성화 만료 환경은 브라우저 다운로드와 파일 입력으로 대체.

## 선택 Kimodo
기본 OFF. 사용자가 별도로 실행한127.0.0.1:8765 엔진에 메모리 전용 연결 코드로 연결한다. 정확히 지정한 웹 Origin만 허용, Bearer 연결 코드, 제한된 작업 API, 사용자 소유 작업만 취소. HF 인증키는 고급 모델 설치 요청에서만 로컬 엔진으로 전달. 정적 웹앱과 Vercel은 모델을 실행하거나 HF 인증키를 저장하지 않는다.

HTTPS→로컬 엔진은 브라우저 로컬 네트워크 권한이 필요할 수 있다. 로컬 연결 검사와 실제 배포 Origin의 승인·CORS·브라우저 권한 결과를 구분한다. 모델 접근 승인 및 새 추론은 여전히 미검증.

## 구현 순서
1. 최소 소스/라이선스/자산 복사, Electron과 실행기 제외, 패키지·Vercel 설정.
2. 브라우저 파일/예제/로컬 작업 어댑터 및 테스트.
3. 별도 Python 선택 커넥터, 인증·Origin·작업 경계 및 취소 테스트.
4. 브라우저 UI 연결 안내 및 전체 편집·파일·영상 실검증.
5. npm ci/build·배포 파일 검사·소스 업로드 ZIP 생성·사용법/목록 기록.

## 검증
기본 접속 시 localhost 요청0·설치 요구0; 실제 GLB/DRACO; 저장다운로드와 재업로드 복원;150프레임 예제;1초30프레임 WebM 디코딩;고급 OFF/연결 오류;커넥터 인증·CORS·허용Origin·입력검사. 공개Vercel 배포 성공을 로컬 검사로 대체 주장하지 않는다.

## 분업
실행 계획 스킬의 지침에 따라 브라우저 어댑터와 선택 커넥터를 독립 에이전트가 담당하고, 주 에이전트가 웹UI·배포구성·통합검증·인계를 담당한다. Git 저장소가 없는 새 작업 폴더이므로 별도 새 버전 폴더로 격리한다.
