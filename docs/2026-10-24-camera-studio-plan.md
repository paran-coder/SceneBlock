# SceneBlock v2.10.0 카메라 구도 편집과 오른쪽 탭

승인 근거: 사용자가 제안한 카메라 표시/뷰어/시간별 기록/경로와 오른쪽 탭 설계를 논의 후 구현 요청함.

1. 기존 구조·저장 검증 확인 및 백업. camera.keys에 절대 시간, 위치, target, 화각, roll을 기록. 키가 있으면 기존 프리셋 계산보다 우선. 기존 프로젝트는 그대로 유지.
2. 카메라 선택·이동·회전 프록시와 선택 카메라 촬영 범위 표시. 편집 초안은 현재 시간과 연결하고 기록/취소 전 시간 이동·재생·저장·내보내기 방지. 실제 작은 뷰어는 장면 카메라로 별도 렌더링.
3. 현재 편집 시점 적용/선택 카메라 시점으로 편집, 기록/교체/삭제, 타임라인 다이아몬드, 경로 점 높이 편집. 기록 키와 경로는 위치를 공유하고 추적 대상은 방향 계산에 적용.
4. 오른쪽 기본/인물 연출 또는 기본/카메라 연출 탭. 인물의 긴 자세 영역은 접기 그룹으로 정리. 왼쪽 목록 유지. 키 선택 시 카메라 연출 탭 자동 선택.
5. 단위·실제 Chrome 검사, 실제 영상 출력·키 저장/열기·Undo/Redo·초안 보호·뷰어와 촬영 결과 일치, 빌드·업로드 패키지 검증.

자체 점검: 설계 9/10. 경로 시간은 키의 절대 시간 기준. 같은 카메라를 여러 컷에서 사용해도 키 시간이 달라지지 않음. 프리셋으로 복귀 시 키 우선 안내 및 명시적 키 삭제로 충돌 방지.
