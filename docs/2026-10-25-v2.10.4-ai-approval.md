# SceneBlock 웹 v2.10.4 / AI 연결 프로그램 v2.7.0

## 변경
- 연결 허용 창을 웹의 어두운 배경·초록 강조·한글 용어와 통일. 정확한 사이트 주소와 AI 실행 시점을 명시하며 버튼은 취소 / 연결 허용.
- 설치·업데이트·확인 화면도 같은 공용 WinForms 스타일 사용. 정상 승인에 오류/물음표 아이콘을 표시하지 않음. 운영체제의 별도 보안/프로토콜 승인 화면은 변경하지 않음.
- 웹 health 버전 노출, 명시적 버전 확인, 구버전 업데이트 안내·새 EXE 링크·현재 탭 연결 해제 준비. 호환되는 구버전을 강제 차단하지 않음.
- 새 설치 위치는 현재 사용자 LocalAppData/SceneBlock/AI/2.7.0. 이전 디렉터리와 CLI 로그인 파일에 쓰지 않음. URL 등록 명령 전환 시 이전 값 백업.
- 기존 승인 티켓은 120초짜리 일회성 데이터이고 연결 세션도 만료되므로 이관하지 않음. 업데이트 후 다시 연결·사이트 승인 필요.
- 다른 버전/프로그램이 포트를 사용하는 경우 종료시키지 않고 한글 안내. 이전 프로세스는 모든 탭 연결 해제 후 약 90초 유휴 종료를 기다림.
- 이전 v2.6.0 설치 파일은 기존 배포 ZIP과 바이트 단위로 동일하게 보존.

## 검증
- 버전 노출 검사 실패를 먼저 재현 후 구현. 전체 단위 150/150 통과. 실제 로컬 health의 두 경로가 v2.7.0을 반환하며 provider를 호출하지 않는 것 확인.
- 웹 브라우저 업데이트 검사 4항목: 구버전/최신/더 높은 버전/버전 미확인 및 업데이트 준비 안내. HTTP 요청은 /health만 사용한 모의 검증이며 AI 계정이나 프로토콜 실행 없음.
- 도구/카메라 표시 회귀 6항목, 카메라·탭·저장·영상 회귀 9항목 통과. 이번 브라우저 검사 합계 19항목.
- 새 설치기 컴파일 및 --verify-payload 통과. 새 승인 EXE가 페이로드에 포함됨을 확인.
- 별도 작업 폴더 --test-upgrade: 이전 버전 파일 보존, 새 버전 추출, 동일 파일 재실행, 변경된 기존 파일 보존·거부 확인. 실제 설치/레지스트리/CLI 로그인에는 쓰지 않음.
- 실제 WinForms 메시지 루프에서 연결 허용/취소 버튼, Escape/닫기의 승인 여부 확인. 허용만 승인됨. 승인창과 설치기 렌더 PNG를 직접 확인.
- PowerShell -ValidateOnly로 새 런처의 공식 사이트 URI 파싱 확인. 이 모드는 승인이나 티켓/프로세스 실행을 하지 않음.
- 재현 스크립트 scripts/2026-10-25-verify-ai-installer.ps1. 결과 dev/2026-10-25-ai-installer-check, dev/2026-10-25-ai-update-verification, dev/2026-10-25-ai-web-verification.
- 실제 사용자 PC에 업데이트 설치하거나 실제 계정 AI 장면 생성은 수행하지 않음. 모든 PC의 OS 보안창/DPI/설치 성공을 검증한 것은 아님. 연결 프로그램은 기존과 같이 서명되지 않은 x64 베타.
- 자체 점검: 설계 9/10, 구현 8/10, 검증 9/10.

## 배포
웹 누적/전체 소스 패키지와 새 설치 EXE를 함께 제공. 기존 사용자는 웹 반영 뒤 새 설치 파일로 업데이트해야 새 승인창이 표시됨. 별도 SceneBlock Git 저장소와 공개 배포는 수정하지 않음.
