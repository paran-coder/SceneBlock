# Previs Web v2.0.0 검증 기록

기존 데스크톱 v1.0.0/v1.1.0과 작업 폴더 최상위 문서 4개를 보존하고 새 웹 버전을 작성했습니다. 모델은 추가 다운로드하지 않았습니다.

- 브라우저 어댑터·장면·모션 단위 테스트: 24/24 통과.
- 선택 Python 커넥터: 실제 루프백 서버 인증·Host·Origin·CORS·작업 취소 등 4/4 통과. 모델 설치와 추론은 실행하지 않음.
- 실제 설치된 Chrome: 정적 앱 시작, GLB 로드, 카페 장면 생성, 촬영 구도, 스크럽·재생, JSON 다운로드/파일 선택 복원, 150프레임 사전 생성 예제, 연결 코드 없는 고급 기능 접근 검사 통과.
- 기본 사용 중 로컬 엔진 및 외부 서비스 요청 0, 페이지 오류 0.
- 실제 WebM 다운로드: VP8, 1056×594, 1초, 디코딩된 30프레임, 83,070바이트.
- 별도 소스 복사본에서 npm ci → production build → 정적 패키지 검사 → 24개 테스트 재현.
- 브라우저 테스트 서버는 vercel.json의 보안 헤더를 적용함. 실제 Vercel 배포를 대신하지 않음.

자체 평가: 브라우저 전환 9/10, 선택 엔진 경계 9/10, 배포 준비 9/10. 실제 GitHub/Vercel 배포, 배포 HTTPS에서 로컬 엔진 권한 허용, 새 Kimodo GPU 추론은 미검증입니다. 브라우저 네이티브 저장 대화상자는 단위 테스트, 실제 파일 저장·복원은 다운로드/파일 입력 방식으로 검증했습니다.

웹 배포 소스에는 Python 인터프리터·CUDA 의존성·모델·인증키를 넣지 않았습니다. 다운로드 ZIP의 Python 소스는 선택 기능이며 기본 사용 시 실행되지 않습니다. 신뢰할 수 있는 Chrome 데스크톱 환경을 검증 기준으로 삼았고 모바일 편집과 다른 브라우저의 영상 코덱 호환성은 보장하지 않습니다.
