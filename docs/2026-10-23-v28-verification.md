# SceneBlock v2.8.0 변경·검증 기록

## 범위와 보존
사용자의 앞선 포즈·레이어·AI 안내·버튼 중복 제보와 v2.7.0 검수 A01–A16을 함께 반영했다. v2.7.0, 이전 버전, 원본 SceneBlock, 최상위 기존 문서·ZIP은 수정하지 않았다. v2.8.0 폴더에서만 수정했다. 새 모델 다운로드·외부 계정 로그인·GitHub 쓰기·Vercel 배포는 하지 않았다. 기존 로컬 개발 의존성은 새 폴더로 복사했으며 외부 설치는 하지 않았다.

## 검수 항목 대응
| 항목 | 반영 |
|---|---|
| A01 현재 자세가 T자세로 변경 | 현재 평가된 관절 회전을 중립 자세 기준 초안으로 캡처. 현재 자세 편집과 중립 시작을 구분 |
| A02 부위와 관절 불일치 | 부위 안 관절 자동 선택, 부위 밖 관절 목록 제외 |
| A03 빈 포즈 레이어 | 키 Delete·패널 삭제·클립 Delete에서 마지막 키/클립 제거와 레이어 정리·기본 동작 복귀 |
| A04 편집 대상 갑자기 전환 | 재생 시간 기준 암묵적 클립 선택 제거. 명시적 선택 우선, 편집 대상 표시 |
| A05 인물 회전 덮어쓰기 | 자동 경로 방향 옵션. 수동 회전 시 자동 방향 해제 |
| A06 부위 변경 초안 손실 | 부위 변경 시 초안 유지·관절 선택 갱신 |
| A07 숫자와 저장값 불일치 | 편집 중 패널 숫자를 편집기의 초안에서 읽음 |
| A08 새로고침 손실 | 로컬 복구본·복구 안내·이탈 경고·프로젝트 열기 전 미저장 확인 |
| A09 포즈 버튼 혼선 | 프리셋 즉시 기록과 초안 저장 구별. 저장·취소는 편집 중에만 표시. 구간 적용은 고급 메뉴 |
| A10 AI 버튼 중복 | 왼쪽 설정 진입점 하나. 1단계 연결 기능과 2단계 공식 도구 설치/로그인 명확화 |
| A11 부위 추천·단순 그림 | 반대쪽 전용 프리셋 추천 제외, 단순 인체 그림·반복 정지 자세 접미사 제거 |
| A12 홈 Space | 편집 화면 범위와 버튼 기본 키 동작 존중 |
| A13 내보내기 상태 | 내보내기 전 비활성 값을 개별 복원 |
| A14 소품 회전 저장 | 현재 데이터가 지원하는 Y축만 노출. 소품 X/Z 회전 지원을 추가한 것은 아님 |
| A15 무효 카메라 종료 조절 | 선형 이동일 때만 종료 구도 캡처 표시 |
| A16 lower | 하체 한글 표기 |

포즈 부위별 추천은 기존 라이브러리 이름을 이용한 필터다. 새로 모션 데이터를 생성하거나 프리셋 121개를 수작업 재분류한 것은 아니다. 자연스러운 발 접촉·IK는 이번 변경에 포함하지 않는다.

## 검증 결과
- 회전/부위 추천 신규 단위 테스트 2개가 수정 전 실패, 수정 후 통과.
- 신규 브라우저 회귀 테스트는 수정 전 오른팔 관절 미선택으로 실패, 수정 후 통과.
- 전체 Node 단위·로컬 커넥터 계약 테스트: **126/126 통과**. 실제 유료 계정 추론 아님.
- `tests/2026-10-23-v28.e2e.mjs`: 9개 흐름 통과. 부위 자동 선택, 필터·부위 변경 후 초안 저장, 빈 레이어 정리, 편집 대상 유지, 현재 자세 유지, 중복 UI, 홈 Space, 복구, 카메라 설정, 회전.
- `tests/2026-10-23-v28-integration.e2e.mjs`: 8개 흐름 통과. 실제 관절 회전축 드래그·숫자·키 저장·Undo/Redo, 고스트와 자세 보간, 파일 저장/열기, 로고 홈, 실제 WebM 출력과 ffprobe, 내보내기 후 AI 비활성 복원.
- `tests/2026-10-23-v28-camera.e2e.mjs`: 11개 흐름 통과. 1280/1600 폭 도구 정렬, 동선 드래그, 타임라인 늘림에 맞춘 도착, 컷 경계별 구도, 카메라 움직임, 카메라 경로, 저장/열기, 컷 순서 영상 출력.
- `tests/2026-10-23-v28-layout.e2e.mjs`: 7개 그룹 통과. 타임라인 공통 축·화면 넘침, 인물 색상/이름, 클립 조절·삭제, 한글 포즈/검색, 소품, 우클릭 이동·Space, 파일 왕복.
- `npm run build` 통과. `npm run check:package` 통과: 정적 파일 286개, 모델 가중치 없음.
- 검수 이미지를 직접 확인했다. 증거는 새 버전의 `2026-10-23-verification` 안에 있다.

과거 v2.3·batch 테스트에는 이전 UI 위치/펼침 상태를 전제로 한 부분이 있어 처음 실행 시 실패했다. 이를 숨기지 않고 현재 하위 메뉴·고급 메뉴를 실제로 여는 v2.8 테스트를 별도 작성해 검증했다. `test:batch`, `test:v23` 명령은 현재 UI용 검증으로 연결했다. 이전 테스트 파일은 이력으로 보존했다.

## 제한과 배포
검증은 로컬 Chrome에서 수행했다. 실제 구독 AI 연결·새 PC 설치·브라우저별 로컬 권한과 새 Vercel 배포는 검증하지 않았다. 현재 공개 사이트는 사용자가 업로드·배포하기 전까지 기존 버전이다. 브라우저 복구 저장소는 사이트/브라우저에 종속되며 여러 탭에서는 최근 복구 저장이 우선한다. 프로젝트 파일 저장을 권장한다.
