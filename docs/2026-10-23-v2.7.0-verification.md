# SceneBlock v2.7.0 검증 기록

- Node 자동 테스트124개 통과. 자세 키 전후 적용/부위 추천/로컬 회전 재구성/좌우 반전 포함.
- 실제 Chrome 신규7흐름: 동선 호버 메뉴, 부위별 목록/전체 목록, 키 전용 타임라인과 기본 구간 밖 키, 시간별 고스트 위치·고스트 클릭, 범위 밖 기본 동작 유지와 중간 보간,3D 관절 선택과 실제 회전 조작기 드래그(카메라 유지), 숫자 정밀 조정·해당 키 저장·Undo/Redo, 프리셋 선택 없이 사용자 자세 생성, 저장/열기, 로고 메인/작업 보존, 골반 회전과 발밑 이동, 촬영 고스트 숨김 및 실제2초WebM/ffprobe 검사.
- 기존 기본 편집10흐름, 레이어11흐름 및 포즈 적용5흐름 회귀 통과. 동선 드래그/이전 시점 복귀는1280/1600에서 통과. AI 모의 OS승인+실제 로컬 HTTP 흐름4개 통과. 사용자 계정 AI 생성은 실행하지 않음.
- Vite 프로덕션 빌드 및 정적 구성 검사. 전체본과 v2.6.0 기준 패치의 내용/해시 확인. 기존 AI 설치 EXE v2.6.0을 그대로 보존하여 호환성 유지.

개발 중 발견한 카메라 동반 회전, 키 트랙의 긴 선택 테두리, 초안 취소 후 조작기 모드 복구, 고스트 재계산 성능/공유 자원 해제 처리를 보완했습니다. 자세 편집은 회전 방식이며 IK·물리 접지 생성은 포함하지 않습니다. 원본 저장소 영상과 완전한 기능 동등성을 검증했다는 뜻은 아닙니다.

이전 버전·ZIP·원본 저장소·최상위4문서는 보존했습니다. 새 설치/레지스트리/계정 변경/모델 다운로드/원격 배포는 수행하지 않았습니다. 실제 새 PC 설치·HTTPS 로컬 권한·본인 계정 AI 생성은 여전히 미검증입니다.

단계 자체평가: 데이터·부위 정책9/10, 고스트·관절 편집9/10, 브라우저 통합·패키지9/10.
