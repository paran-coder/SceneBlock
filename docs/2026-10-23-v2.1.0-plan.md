## Shared interfaces

- actor.clips optional array of {id,action,start,end,speed,motion:null|motionDocument,poseId?:string,jointOffsets?:{[boneName]:[xDegrees,yDegrees,zDegrees]}}. Allowed actions idle/walk/run/wave/sit/turn/pose; half-open intervals, no overlap, max 64. actor.path remains independent and follows actor.start/end, retains up to 512 3D points. actor.modelKey optional known asset filename, default existing female model.
- evaluateActor(actor,time) returns old fields plus motion, poseId, jointOffsets, clipId. Gaps idle, no stale pose. motion comes from active clip or legacy actor when no clips. clip localTime=(time-clip.start)*speed; route uses actor.start/end independently.
- camera.motion optional {type:'linear'|'static'|'orbit'|'dolly'|'pan',easing:'linear'|'easeInOut',angle:number}. orbit rotates start offset around target by angle degrees; dolly uses endPosition or 50% distance default; pan rotates view direction; linear keeps old behavior. camera.followActorId optional valid actor ID, moves position by actor position delta since t=0, targets actor position+[0,1.2,0].
- Stage.setPathEditing(actorId|null,onChange): drawing mode disables orbit, click ground appends, drag existing handle moves; callback receives full path; finish via UI button/Escape, no mutation during playback. Stage.setTopView(): overhead camera/orbit view. Stage path guide+numbered handles visible for selected actor, hidden in camera/export mode. Root adds Undo transaction per completed gesture.
- Stage actor sync uses actor.modelKey. Async preload all four local GLBs, preserve bind updateMatrixWorld behavior. Stage update uses evaluated state.motion (not actor.motion), state.poseId and state.jointOffsets.
- src/2026-10-23-poses.mjs: exports POSES array [{id,name,category,file,cover?}], CHARACTERS [{key,name}], applyLibraryPose(root,poseDocument), applyJointOffsets(root,offsets). Static files public/topview-assets/poses and covers with original license. Stage caches fetched pose docs, calls resetCharacterPose/applyBasicAction before fresh pose to avoid accumulation.
