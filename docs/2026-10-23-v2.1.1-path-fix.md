# SceneBlock v2.1.1 동선 드래그·시점 복귀 수정

## 실제 배포본 확인

https://scene-block.vercel.app/ 에서 v2.1.0을 확인했습니다. 점 중앙은 그리기 모드에서 드래그됐으나, 모드 종료 후에는 점이 그대로 보여도 드래그하면 경로 대신 편집 화면이 회전했습니다. 점의 기존 선택 영역은 3D sprite 크기에 따라 작아졌습니다. 위에서 보기를 반복 클릭해도 원래 시점으로 복귀하지 않았습니다. 사용자 보고 중 '모든 그리기 모드 드래그가 실패'는 재현하지 않았으므로 그렇게 단정하지 않습니다.

## 변경

- 선택한 인물의 경유점은 점 추가 모드 밖에서도 직접 이동합니다.
- 화면 좌표 기준 18px 이내의 가장 가까운 점을 선택합니다. 커서는 grab/grabbing으로 바뀝니다.
- 점 이동 중 OrbitControls를 차단하며, 원래 점에서 마우스 이동량만큼 옮겨 첫 이동 시 점이 튀지 않습니다.
- 콜백은 현재 프로젝트의 actor ID로 대상을 찾고 드래그 완료 한 번당 Undo 한 건을 기록합니다.
- 위에서 보기는 기존 편집 카메라 위치·각도·up·zoom·target을 보존하는 토글입니다. 복귀 버튼을 명시적으로 표시합니다.
- 전환 전 OrbitControls 감쇠 잔여량을 소진해 이전 마우스 회전이 새 시점에 계속 적용되지 않게 했습니다.

## 검증

- 회귀 테스트를 먼저 추가해 기존 구현에서 2개 실패를 확인한 뒤 수정했습니다.
- 단위 테스트 46/46 통과, production build 통과.
- 전체 Chrome 검사 10개 흐름 통과: 기존 연출/저장/영상 기능과 시점 복귀·비중앙 점 드래그 포함.
- 추가 Chrome 검사: 1280×720, 1600×1000 일반 경사 시점에서 12px 벗어난 드래그, 그리기 완료 후 점 이동, 경로 점 개수 유지, 화면 카메라 고정, 위에서 보기 복귀 모두 통과. 페이지 오류 없음.
- 수정본 원격 배포는 수행하지 않았습니다. 공개 사이트는 사용자가 파일을 올리고 재배포해야 바뀝니다.

기존 v2.1.0 ZIP과 업로드 폴더는 보존합니다. v2.1.0 개발 폴더 안의 소스만 사전 승인된 범위에서 수정했고, 새 v2.1.1 업로드 폴더/전체 ZIP/소용량 패치 ZIP을 별도로 작성합니다. 자체 점검 9/10.
