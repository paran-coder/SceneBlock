# SceneBlock v2.12.1 / AI 연결 프로그램 v2.9.0

설치창에 설치 · 업데이트, 연결 복구, 프로그램 제거, 구버전 정리를 추가했다. 설치된 버전과 현재 웹 연결 버전을 표시한다. 설치 이후 설치폴더의 2026-10-25-SceneBlock-Manager.exe 또는 받은 설치 파일을 다시 실행해 관리한다. Windows 설정의 앱 목록에 별도 항목을 추가하지 않는다.

삭제 전 정확한 파일 경로·빈 폴더·웹 실행 연결·보존 이유를 표시하고 별도 확인한다. 취소·Esc·닫기 시 삭제하지 않는다. 소유권 manifest와 SHA256 또는 알려진 배포 설치기 payload 지문으로 소유권을 확인한다. 미확인/수정 파일과 runtime 하위폴더는 보존하며 잔여 경로를 표시한다. 구버전 정리는 현재 제공 버전 이상 및 웹에 등록된 버전을 유지한다. 전체 제거는 확인된 모든 버전을 대상으로 한다. 변경된 계획·등록·파일, 사용 중이거나 실행상태 확인 실패 시 중단한다. 외부 Codex/Claude 프로그램과 로그인 저장소는 수정하지 않는다. 소유권을 확인할 수 없는 웹 등록은 덮어쓰거나 제거하지 않는다.

실행 중인 관리자를 제거할 때는 임시폴더 복사본에서 확인창을 다시 연다. 원본 프로세스를 강제종료하지 않는다. 임시 복사본은 OS 임시폴더에 남을 수 있다. 서비스/자동실행/예약 삭제는 추가하지 않는다.
