# SceneBlock v2.14.2 · 상단 도구줄 정리

일반 편집의 중복 상태줄을 제거하고 이동·회전을 기존 상단 도구줄에 통합했습니다. 모드·대상·시간을 반복 표시하지 않습니다. 구도 미기록·관절 자세 편집·동선 그리기 중에만 완료/취소 안내를 표시합니다. 동선 조작 설명도 이 안내에 합쳐 겹침을 방지했습니다.
좁은 뷰포트(800px 미만)에서는 카메라 표시·동선·위에서 보기·동선 지우기를 더보기로 이동합니다. 원래 요소와 이벤트를 유지하며, 넓어지면 원래 도구줄로 돌아옵니다. 더보기는 명령 선택·바깥 클릭·Esc로 닫힙니다. 촬영 미리보기에서는 동선 도구를 숨깁니다.
16:9 캔버스·카메라/포즈/타임라인 기능·? 도움말과 패널 접기는 유지합니다. 포즈블럭 JSON 가져오기는 제거된 상태입니다. 연결기2.10.3은 변경하지 않았습니다.
검증: 실제 Chrome 도구줄6흐름 + 기존 UI/카메라/출력12흐름 = 18흐름 통과, 페이지 오류0. 1600/1366/1024/800 화면의 한 줄 표시와 가로 넘침을 확인했습니다. 실제2초WebM60프레임 디코딩·빌드·정적 패키지 검사 통과. Node 전체 테스트는 코드 변경이 UI 모듈/CSS에 한정되어 이번 버전에서 재실행하지 않았습니다. 독립 코드 리뷰 완료. 자체평가9/10.
