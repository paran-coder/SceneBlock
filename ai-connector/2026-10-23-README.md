# SceneBlock AI 연결 프로그램 v2.5.0

SceneBlock 웹사이트가 사용자 PC의 공식 Codex 또는 Claude Code를 실행해 편집 가능한 장면 초안을 받습니다. AI를 사용하지 않는 수동 편집에는 필요하지 않습니다. Blender·Kimodo·대형 모델 다운로드는 필요하지 않습니다.

## 처음 한 번

1. [Node.js 공식 사이트](https://nodejs.org/)에서 22 이상을 설치합니다.
2. 사용할 AI 하나를 고릅니다. [Codex 공식 설치 안내](https://developers.openai.com/codex/cli/) 또는 [Claude Code 공식 설치 안내](https://code.claude.com/docs/en/setup)를 따릅니다. 이 연결 프로그램은 설치 명령을 자동 실행하지 않습니다.
3. PowerShell에서 Codex는 `codex login`, Claude Code는 `claude auth login`으로 본인 계정에 로그인합니다. 사용 가능한 구독과 한도는 제공자 정책을 따릅니다. API 키로 로그인한 경우 별도 API 비용이 발생할 수 있습니다. 연결 화면의 인증 유형을 확인하세요.
4. 이 폴더를 압축 해제하고 `2026-10-23-launch.cmd`를 실행합니다. 콘솔에 표시되는 6자리 코드를 확인합니다.
5. https://scene-block.vercel.app 의 AI 연결 화면에서 코드를 입력합니다. 브라우저가 로컬 네트워크 접근 권한을 묻는 경우, 본인이 실행한 이 연결 프로그램에 연결하기 위한 요청인지 확인합니다.

## 이후 사용할 때

연결 프로그램 실행 → 사이트 연결 → AI 선택 → 장면 설명 → 생성 → 초안 확인·적용. PowerShell에 장면 설명을 직접 입력할 필요는 없습니다. 연결 프로그램 창은 켜두어야 합니다. 브라우저 새로고침 또는 연결 프로그램 재시작 후에는 다시 연결합니다. 닫으면 AI 연결만 중단되며 수동 편집은 계속 사용할 수 있습니다.

## 정보와 한도

- 장면 설명과 간단한 장면 요약이 선택한 AI 제공자에게 전달됩니다. 요청마다 계정 사용 한도가 소비되며 구독·API 과금 방식은 공식 CLI 인증 설정에 따릅니다.
- 연결 프로그램은 비밀번호·로그인 토큰 파일을 읽거나 웹사이트에 전달하지 않습니다. 로그인 상태·인증 유형·버전만 확인합니다.
- 서버는 127.0.0.1:8766에만 열립니다. 공식 배포 Origin 및 지정된 개발 Origin만 허용합니다. 6자리 코드는 실행할 때마다 새로 생기며 인증 토큰은 메모리에만 보관합니다.
- AI는 제한된 장면 JSON만 생성합니다. 새 3D 자산·자연스러운 AI 모션을 생성하는 기능은 아닙니다. 결과의 시간·시선·동선은 미리보기에서 확인하고 수정하세요.
- 요청은 한 번에 1개, 설명 12,000자, 180초 제한입니다. AI 연결 실행은 빈 임시 작업 폴더에서 진행되며 종료 후 제거됩니다. Codex는 read-only sandbox에 사용자 설정·규칙·셸 도구·플러그인을 끈 실행 옵션을 사용합니다. 해당 옵션이 없는 구버전은 생성을 중단하고 업데이트를 요구합니다. Claude는 도구 사용 없음·MCP 엄격 제한·세션 저장 없음·설정 소스 비활성 옵션으로 실행합니다. 전역 설정 파일을 수정하지 않으며 신뢰하는 본인 계정·공식 CLI만 사용하세요. 브라우저 요청이 끊어지면 실행 중인 생성 프로세스를 종료합니다.

## 연결이 안 될 때

- 미설치: 해당 공식 CLI 설치 후 연결 프로그램을 다시 실행합니다.
- 로그인 필요: PowerShell에서 위 로그인 명령을 실행한 후 사이트에서 상태를 다시 확인합니다.
- API 인증: 구독으로 사용하려면 공식 CLI의 로그인 방법을 확인합니다. 사이트는 인증 방법을 자동 변경하지 않습니다.
- 브라우저 차단: localhost/로컬 네트워크 접근 권한을 확인합니다. 브라우저·보안 정책에 따라 HTTPS 사이트에서 로컬 연결이 제한될 수 있습니다.
- 생성 실패: 공식 CLI에서 로그인·요금제 한도·네트워크·버전을 확인하세요. 이 배포의 실제 구독 계정 호출은 자동 테스트하지 않았습니다.

공식 CLI의 설치 및 로그인 정보는 변경될 수 있으므로 위 공식 문서를 우선합니다. 배포 기능 테스트는 가짜 프로세스와 HTTP 계약 검증이며 실제 계정으로 새 장면을 생성한 검증은 별도입니다.
