# SceneBlock AI v2.8.0

Public installer: public/downloads/2026-10-25-SceneBlock-AI-Setup-v2.8.0.exe. The web editor is v2.12.0.

- Installs to the current Windows user's LocalAppData/SceneBlock/AI/2.8.0. Previous version directories and external Codex/Claude login stores are not modified. The previous URL-protocol command is backed up before registration moves to the new version.
- The branded Korean approval dialog displays the exact approved website. Only Connect Allow returns success; Cancel, Escape and Close do not issue approval. The launcher validates origin/nonce first and creates a short-lived ticket only after approval.
- Approval is per launch/session, not a permanently saved website approval. Tickets and bearer sessions are not migrated. Reconnect and approve after an update.
- Existing active connector processes are never killed automatically. Release connections in all SceneBlock tabs and allow about 90 seconds of idle time before reconnecting to the new installation.
- The web checks protocol-2 health versions and recommends 2.8.0 for older compatible installations. A failed health request is not proof that the app is uninstalled. Unknown versions are not treated as broken.
- Node is embedded, and no service, autostart entry, model download, CLI login or AI generation is run by installation/approval alone. The app remains an unsigned Windows x64 beta.

Build with scripts/2026-10-23-build-installer.ps1. It refuses to overwrite an existing output; use -OutputFile for a new candidate path. Verify without installation using scripts/2026-10-25-verify-ai-installer.ps1, which uses isolated workspace folders and never registers the protocol or changes real CLI credentials.


Intent contract: protocol2 health advertises responseFormats scene-plan-v1 and scene-intent-v1. New /generate-intent returns {intent}, with strict source coverage, typed bindings and requirements. Legacy /generate still returns {plan}; request fields cannot switch its internal mode. Both routes share auth, busy lock, disconnect cancellation and isolated read-only provider CLI flags. Intent request budget64KiB; all other routes32KiB. Credentials remain outside browser state. No real provider runs or real installation were performed in this implementation verification.
