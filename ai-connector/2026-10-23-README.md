# SceneBlock AI v2.6.0

Public user entry is the Windows Setup EXE, not the legacy CMD or ZIP. Installs under current-user LocalAppData/SceneBlock/AI/2.6.0 and registers sceneblock://start. Node24.14.1 and its official license are embedded. No system Node installation, admin, startup task or model download is required by the connector.

The EXE asks before installing files and registering the current-user URL protocol. Conflicting unrelated associations and changed existing same-version files are preserved. Previous recognized SceneBlock command is backed up before updating the association.

Website activation -> browser app-open confirmation -> local origin consent -> one-use origin-bound 32-byte nonce ticket -> hidden Node on port8768 -> authenticated expiring tab lease. Web tokens stay in memory. Tabs heartbeat20s, leases65s, idle exit90s after no tab/job. CLI processes have time/output limits and no arbitrary shell commands. Exact production origin https://scene-block.vercel.app plus enumerated localhost development origins only. Other deployment domains require explicit trusted-origin configuration before rebuilding.

Official Codex/Claude CLI installation and login remain user actions in official flows. No password or subscription auth-token extraction. User explicitly consents before scene description and scene summary are sent. API authentication is detected and shown separately from subscription mode. Generated plans are validated, previewed and explicitly applied with Undo.

Build: powershell -File scripts/2026-10-23-build-installer.ps1 from project root. Verify-only flag --verify-payload does not install or register anything. Old 8766 pairing connector is retained only for legacy tests; installed on-demand entry is 2026-10-23-on-demand.mjs.

Runtime and tickets are private installation state and excluded from source releases. Installer is an unsigned Windows x64 beta; clean-machine install and remote HTTPS/browser permissions have not been tested.
