# SceneBlock · 씬블록 v2.10.1

머릿속 장면의 인물 동선·자세·시간·촬영 구도를 편집하는 웹 프리비즈 도구입니다.

## v2.10.1 수정
- 카메라 초안 중 타임라인 포인터/키보드 선택·드래그·삭제 차단.
- 초안의 카메라와 시간이 일치할 때만 구도 기록. 동선/프리셋 등 프로젝트 변경도 기록·취소 전 차단.
- 단위 테스트 147개, 브라우저 23개 항목 및 실제 영상 출력 검증 통과.

## v2.10.0 추가
- 편집 장면의 카메라 아이콘, 선택 카메라 촬영 범위, 이동·회전 조작.
- 왼쪽 아래 실제 카메라 뷰어, 크기 변경·접기.
- 현재 시간의 위치·방향·화각·기울기 기록, 타임라인 구도 키, 보간·삭제·Undo/Redo.
- 카메라 경로와 구도 위치 공유, 경유점 높이 편집. 기록 구도가 기존 효과보다 우선.
- 오른쪽 기본/인물 연출 또는 기본/카메라 연출 탭, 긴 항목 접기.
- 초안 기록/취소 보호. 단위 검사 146개, 신규 브라우저 9종 및 회전 회귀 4종 통과.

## v2.9.1 수정
- 인물·소품 회전 도구 선택 시 바로 X/Y/Z 회전구 표시.
- 세 축 각도 저장/열기, Undo/Redo, 자세 고스트 및 영상 출력 반영.
- 기존 Y축 방향 보존, 인물은 골반 중심 회전.

## v2.9.0 추가
- 어린이 120cm, 청소년 155cm 기본 키 및 머리 비율 보정.
- 캐릭터 전신 크기 25~200%, 초기화 및 저장·실행 취소.
- 일반 소품 / 탈것 분류, 자동차·SUV·승합차·버스·트럭·오토바이·자전거.
- 동선 그리기 진입 시 첫 이동 구간의 시작점으로 복귀.
- 기존 v2.8.3 카메라 움직임 수정 포함.

## v2.8.0 수정
- 현재 화면 자세에서 관절 편집 시작. 중립 자세로 시작은 별도 버튼입니다.
- 부위에 맞는 관절 자동 선택, 라이브러리 필터·부위 변경 시 편집 초안 유지.
- 마지막 포즈 키/클립 삭제 시 빈 레이어 정리와 기본 동작 선택 복귀.
- 시간 이동 뒤 다른 설정을 바꿔도 편집 대상이 바뀌지 않음.
- 포즈의 즉시 기록과 편집 저장을 구분하고 구간 적용은 고급 메뉴로 이동. 단순 인체 그림 제거.
- AI 연결 진입점 하나로 통합. SceneBlock 연결 기능과 공식 AI 도구 설치·로그인은 별도 단계로 안내.
- 인물 수동 회전 시 자동 경로 방향 해제. 골반 높이에서 Y축 회전, 발밑 이동 유지. 소품도 저장 가능한 Y축 회전만 노출.
- 브라우저 로컬 복구 저장과 미저장 이탈 경고, 카메라 방식별 유효한 조절, 홈 화면 단축키 범위 및 내보내기 비활성 상태 복원.

## GitHub / Vercel
`2026-10-23-github-upload` 폴더 **안의 전체 내용**을 저장소 루트에 올립니다. `public`도 포함해야 합니다. `node_modules`, 로컬 검수 기록, runtime은 업로드하지 않습니다.
Vercel: Build `npm run build`, Output `dist`. GitHub 반영 후 Vercel에서 새 배포를 확인하세요. 기존 배포 사이트는 이 로컬 작업만으로 변경되지 않습니다.
로컬 개발: `npm ci` 후 `npm run dev`. HTML 더블클릭 실행은 지원하지 않습니다.
