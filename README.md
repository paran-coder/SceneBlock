# SceneBlock · 씬블록 v2.1.0

머릿속 장면을 움직여 보는 프리비즈 스튜디오.

## 이번 버전에서 보완한 기능

- 바닥을 클릭해 동선 그리기, 번호가 붙은 경유점 드래그 및 좌표 수정·삭제.
- 한 인물에 걷기 → 손 흔들기 → 포즈 등 여러 행동 구간 배치.
- 타임라인에서 행동과 카메라 컷을 직접 이동하고 양끝을 드래그해 길이 조정.
- 공식 Topview 정지 포즈 121개 검색·선택·미리보기, 관절 10곳의 XYZ 각도 보정.
- 캐릭터 4종 선택. 현재 캐릭터는 모두 1.75m 기준으로 정규화하므로 Child는 비율이 다르고 키는 동일합니다.
- 카메라 고정·시작/종료 이동·돌리 인·오빗·팬, 가감속, 인물 따라가기.
- Undo/Redo, 기존 프로젝트 불러오기, 새 동선·클립·포즈·카메라 설정 저장·복원.
- 내보내기 동안 편집 잠금, 필요한 캐릭터·포즈 로드 대기, 누락 포즈의 명시적인 오류.

기본 편집은 브라우저에서 실행합니다. Blender, CMD, Python, 모델, 로그인, API 키가 필요하지 않습니다. 현재 자연어 장면 구성은 카페·인원·기본 행동을 처리하는 규칙 파서이며 GPT 호출이 아닙니다.

## 바로 사용하기

1. 인물을 선택하고 **위에서 보기 → 동선 그리기**를 누릅니다. 바닥 클릭으로 점을 추가하고 번호 점을 드래그합니다. **그리기 완료** 또는 Esc로 종료합니다.
2. 오른쪽 시작·종료 시간은 전체 동선 이동 시간입니다. 아래 **행동 순서**는 동선과 별도로 시간 구간별 행동을 정합니다.
3. 선택한 행동의 종료 시간을 줄인 뒤 **행동 추가**로 다음 구간을 만듭니다. 타임라인 중앙을 끌어 이동하고 양끝 핸들을 끌어 길이를 조정합니다. 겹치는 구간으로 이동하지 않습니다. 빈 구간은 서 있기입니다.
4. **포즈 라이브러리**에서 포즈를 선택하고 미리본 뒤 적용합니다. 정지 포즈이며 관절 각도로 추가 보정할 수 있습니다. 포즈 이름은 원본 영문입니다.
5. 카메라를 선택해 운용·가감속·추적 인물을 정합니다. 인물 추적은 카메라를 인물 이동량만큼 옮기며 상체를 바라봅니다. 따라가기와 팬을 함께 쓰면 추적 대상 바라보기가 우선합니다.
6. **촬영 미리보기**와 재생으로 확인합니다. 동선 가이드·조작 도구는 촬영 화면과 영상에서 숨깁니다.
7. **프로젝트 저장**으로 JSON을 내려받고 **열기**로 복원합니다. 자동 저장은 없습니다. Ctrl+Z / Ctrl+Shift+Z로 실행 취소·다시 실행합니다.
8. **영상 내보내기**로 30fps WebM을 저장합니다. Chrome 데스크톱에서 검증했으며 WebCodecs 지원이 필요합니다. 현재 영상 크기는 편집 화면 크기에 따릅니다.

## GitHub → Vercel 배포

업로드용 폴더 **안의 내용**을 저장소 최상위에 올립니다. `public`을 포함해야 합니다. ZIP 자체나 개발용 node_modules/dist/cache는 올리지 않습니다. 선택 엔진 소스 ZIP이 크므로 GitHub Desktop/Git을 통한 업로드가 편리합니다.

Vercel 설정: Framework **Vite**, Root Directory **./**, Install **npm ci**, Build **npm run build**, Output **dist**, Node **24.x**. 환경변수 없이 기본 편집이 실행됩니다. 이 버전은 아직 원격 GitHub에 올리거나 Vercel에 재배포하지 않았습니다.

이전 v2.0.0의 JSON 프로젝트는 불러올 때 행동 클립으로 변환합니다. v2.1.0에서 저장한 파일을 이전 앱에서 다시 편집하면 새 클립·카메라 설정은 제대로 재생되지 않을 수 있으므로 새 버전을 사용하세요.

## 선택형 Kimodo와 남은 범위

Kimodo는 별도 Python/CUDA 엔진과 모델 접근 승인이 필요한 선택 기능입니다. [로컬 엔진 안내](docs/2026-10-23-local-engine.md)를 참고하세요. 기본 편집에서는 엔진으로 요청하지 않으며 모델을 자동으로 다운로드하지 않습니다. 동봉 엔진 소스 ZIP은 기존 v2.0.0 프로토콜을 그대로 사용합니다.

이번 릴리스는 브라우저 연출 기능의 1차 보완입니다. 그린 경로·포즈·손발 위치를 Kimodo 생성 제약으로 전달하는 기능, 새 GPU 추론, IK 편집, 행동 간 블렌딩/발 접지 보정, AI 자연어 대화, 외부 GLB 가져오기, 자동 충돌/프레이밍 검사, 원본 Topview 프로젝트 호환, 해상도·이미지 출력 선택은 아직 제공하지 않습니다. 현재 기본 걷기는 절차적 미리보기이며 사실적인 보행이 아닙니다.

생성된 Kimodo 모션은 제자리 동작으로 적용하고, 장면 안의 이동은 그린 동선으로 제어합니다. 경로와 보행을 AI로 함께 생성하는 방식과 다릅니다. 실제 Vercel HTTPS에서 로컬 엔진 연결 및 새 모델 추론은 별도 검증이 필요합니다.

## 개발 검증

```powershell
npm ci
npm test
npm run build
npm run check:package
npm run test:browser
npm run dev
```

브라우저 검사는 설치된 Chrome 및 ffprobe가 있는 개발 PC 기준입니다. 일반 사용자에게는 필요하지 않습니다. 검증 결과와 제한 사항은 [릴리스 검증 기록](docs/2026-10-23-v2.1.0-verification.md)을 확인하세요.
