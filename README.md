# SceneBlock · 씬블록 v2.11.1

머릿속 장면의 인물 동선·자세·시간·촬영 구도를 편집하는 웹 프리비즈 도구입니다.

## v2.11.1 · 인물 관계와 촬영 방향
- 좌석 앞쪽/상대 인물/카메라 방향 일치, 도착 후 상대 바라보기.
- 정지 카메라의 두 인물 프레이밍과 실제 소품 메시 가림 검사, 없는 손동작 구도 변경, 누락 요청 요소 표시.
- 소수 좌표 직선 경로 끝점 오류 수정. 상세: docs/2026-10-25-v2.11.1-scene-relations.md
- 자동180개·관계 브라우저5항목·기존 구성/카메라17항목 통과. 실제 AI 생성·배포는 미검증.

## v2.11.0 · AI 구성안 보정과 충돌 검사
- 실제 지원 동작/소품 치수 안내, 미지원 요청 표시와 잘못 명명된 행동 레이어 비활성화.
- 좌판 높이와 캐릭터 골반 정렬, 프로젝트 저장/열기와 수동 변경 시 좌석 연결 해제.
- 소품 우회 경로, 인물 겹침·카메라 충돌 검사. 해결되지 않으면 적용 차단.
- 웹만 교체. PC 연결 프로그램 v2.7.0 유지. 실제 AI 생성/배포는 미검증.
- 자동168개, 신규 브라우저8종 및 기존 회귀25종 통과. 상세: docs/2026-10-25-v2.11.0-scene-safety.md

## GitHub / Vercel
`2026-10-23-github-upload` 폴더 **안의 전체 내용**을 저장소 루트에 올립니다. `public`도 포함해야 합니다. `node_modules`, 로컬 검수 기록, runtime은 업로드하지 않습니다.
Vercel: Build `npm run build`, Output `dist`. GitHub 반영 후 Vercel에서 새 배포를 확인하세요. 기존 배포 사이트는 이 로컬 작업만으로 변경되지 않습니다.
로컬 개발: `npm ci` 후 `npm run dev`. HTML 더블클릭 실행은 지원하지 않습니다.
