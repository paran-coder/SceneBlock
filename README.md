# SceneBlock · 씬블록 v2.3.0

머릿속 장면을 움직여 보는 프리비즈 스튜디오.

## 이번 일괄 수정

- 카메라 이름이나 타임라인 컷을 클릭하면 컷 시작으로 이동하고 촬영 미리보기로 전환합니다. 현재 카메라 이름을 화면에 표시합니다. 컷 사이 빈 구간은 이전 컷을 유지하고, 새 장면 구성 시에도 와이드·인물 A·오버숄더 3개 컷을 만듭니다.
- 걷기·달리기 클립을 늘이거나 줄이면 동선 도착 시간도 함께 바뀝니다. 여러 이동 행동은 전체 동선을 나눠 이동하며 중간 정지 행동에서는 위치를 유지합니다.
- 번호 점과 동선 가이드는 동선 편집 중에만 나타납니다. 상단 모드·동선 버튼은 넓은 화면에서 한 줄, 좁은 화면에서는 줄바꿈합니다. 안내는 동선 편집 중에만 표시합니다.
- 카메라 운용 13종: 고정, 시작→끝, 전진·후진, 좌우 이동, 상승·하강, 팬, 틸트, 오빗, 줌, 돌리 줌, 빠른 줌, 핸드헬드, 직접 그린 동선. 한글 설명과 움직이는 개념 예시를 제공합니다.
- 거리·방향·각도·화각·흔들림·가감속·추적 인물과 카메라 XYZ 경유점을 조절합니다. 줄어든 움직임 환경설정에서는 개념 예시를 정지합니다.
- 기존 한글 포즈 121개, 인물 이름·색상, 소품 9종, 타임라인 이동·트림, 저장·열기, 스페이스 재생과 우클릭 이동을 유지합니다.

## 조작 방법

장면 설명의 규칙 파서로 초기 장면을 만들거나 인물·소품을 직접 추가합니다. 현재 자연어 기능은 GPT가 아닙니다.

인물을 선택하고 위에서 보기 → 동선 그리기를 누릅니다. 바닥 클릭으로 점을 추가하며 번호 점을 드래그해 이동합니다. 그리기 완료/Esc 뒤에는 점과 선이 숨겨집니다. 다시 동선 그리기를 누르면 기존 점을 드래그할 수 있습니다. 위에서 보기 버튼은 이전 시점으로 바뀌어 원래 구도로 돌아갈 수 있습니다.

오른쪽 행동 순서의 시작·종료가 이동 시간에도 적용됩니다. 인물의 예전 독립 동선 시간 입력은 숨겼습니다. 종료를 줄인 뒤 행동 추가로 다음 구간을 만듭니다. 타임라인 중앙을 드래그하면 시간 이동, 양끝 핸들은 길이 조절입니다. 드래그 중 표시되는 초를 확인하세요. 빈 행동 구간은 서 있기입니다.

포즈 목록은 패널 안의 고정 높이 스크롤 목록입니다. 한글/영문으로 검색하고 선택 후 미리보기 아래 적용 버튼을 누릅니다. 정지 포즈이며 기본 동작·관절 각도로 보완할 수 있습니다.

카메라 이름 또는 타임라인 컷을 클릭해 바로 확인합니다. 재생하면 컷 순서를 따릅니다. 컷에 배치하지 않은 카메라도 단독 미리보기가 가능하며 영상 출력은 항상 저장한 컷 순서를 사용합니다.

카메라 움직임을 선택한 뒤 거리·각도에 음수를 입력하면 반대 방향이 됩니다. 줌은 화각만, 전진·후진은 위치를 변경합니다. 직접 동선은 운용에서 카메라 동선 → 카메라 동선 그리기 → 화면 클릭으로 추가하고 XYZ 숫자로 높이를 조절합니다. 초기 그리기 평면은 카메라 시작 높이이며, 상단 위에서 보기로 경로를 잡기 편합니다. 촬영 미리보기에는 동선·조작 가이드가 숨겨집니다.

프로젝트 저장/열기로 JSON을 PC에 저장·복원합니다. 자동 저장은 없습니다. Ctrl+Z / Ctrl+Shift+Z로 실행 취소/다시 실행합니다. 영상은 편집 화면 크기의 30fps WebM이며 Chrome 데스크톱에서 검증했습니다.

## GitHub → Vercel

전체 업로드 폴더 안의 내용을 저장소 최상위에 올립니다. public도 포함합니다. 소용량 v2.2.0→v2.3.0 패치는 현재 v2.2.0 저장소의 같은 경로에 교체하고 기존 public을 유지하세요. 더 이전 버전이면 전체 소스를 권장합니다.

Vercel: Framework Vite, Root ./, Install npm ci, Build npm run build, Output dist, Node 24.x. 기본 편집에 환경변수·계정·모델 설치가 필요하지 않습니다. 이 버전은 아직 원격 GitHub/Vercel에 반영하지 않았습니다.

## 유지되는 제한

Kimodo는 별도 로컬 Python/CUDA 엔진과 모델 접근 승인이 필요한 선택 기능입니다. [엔진 안내](docs/2026-10-23-local-engine.md). 다운로드 ZIP은 기존 v2.0.0 엔진 소스이며 기본 편집에서 요청하지 않습니다. 새 모델 다운로드·GPU 생성은 이번에 실행하지 않았습니다.

그린 동선/포즈를 AI 생성 제약으로 전달, IK, 행동 블렌딩·발 접지 보정, 외부 GLB 등록, 자동 충돌 검사, 원본 프로젝트 형식 호환, 출력 해상도 선택은 제공하지 않습니다. 기본 걷기는 절차적 미리보기입니다. 캐릭터 키는 현재 모두1.75m로 정규화됩니다. 이전 프로젝트는 열 수 있지만 새 카메라 움직임을 저장한 파일은 이전 앱에서 열지 못할 수 있습니다. 기존 문서에 걷기 클립과 독립 동선 시간이 다르게 저장되어 있으면 이제 걷기 클립 시간을 따릅니다. 핸드헬드는 절차적 효과이며 광학 시뮬레이션·초점 이동·충돌 회피는 제공하지 않습니다. 돌리 줌의 화각은 10–120도 범위로 제한됩니다.

Topview Studio 전체를 이식한 제품이 아니라 Three.js 독립 편집기에 공식 자산을 사용하는 앱입니다. 출처/라이선스는 public/topview-assets/LICENSE, NOTICE, 2026-10-23-pose-attribution.md와 Kimodo·Three.js/DRACO 동봉 라이선스를 확인하세요.
