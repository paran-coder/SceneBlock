# SceneBlock · 씬블록 v2.7.0

머릿속 장면을 움직여 보는 프리비즈 스튜디오.

## v2.7.0 변경

- 동선 그리기 호버/클릭 하위 메뉴에서 직선·곡선을 선택합니다.
- 부위별 정지 자세 추천, 적용 부위 그림과 전체121개 보기로 동작/정지 자세를 구분합니다.
- 시간별 목표 자세를 다이아몬드 키와 반투명 고스트 메시로 표시합니다. 키 사이 보간과 전후 기본 동작 복귀/유지를 선택합니다. 유지 포즈 클립은 별도입니다.
- 관절 점을 선택하면 그 관절 하나에만 회전축을 표시합니다. 직접 드래그·숫자 입력·좌우 반전·초기화 후 선택 시간 키에 저장합니다. 프리셋 없이 중립 자세에서 만들 수 있습니다. IK는 포함하지 않습니다.
- 전체 인물 회전은 골반 높이의 수직축, 이동은 발밑에서 조작합니다.
- 로고로 작업을 보존하며 메인 이동, 새 장면 전에 미저장 변경 확인. AI 연결 설치와 공식 CLI 설치·로그인을 명확하게 구분합니다.
- [새 사용 안내](docs/2026-10-23-v2.7.0-manual.md), [검증 기록](docs/2026-10-23-v2.7.0-verification.md)

AI 연결 설치기는 기존 v2.6.0을 그대로 사용합니다. 이번 버전은 웹 편집 기능 변경이며 기존 설치자는 재설치하지 않습니다. GitHub 업로드에는 public과 ai-connector를 포함한 업로드 폴더 **내용 전체**를 저장소 루트에 올립니다. Vercel build/output은 기존과 같습니다.

## v2.6.0 변경

- Windows EXE로 최초 설치한 뒤 웹의 AI 연결 버튼으로 숨김 실행합니다. ZIP·CMD 유지·연결 코드 입력을 없앴습니다. 설치기는 Node 실행 환경과 라이선스를 포함합니다.
- AI 설정은 설치·로그인·상태 안내에만 사용합니다. 평소에는 왼쪽 구성 방식과 장면 설명에서 구성·미리보기·적용합니다.
- 직선 그리기/곡선 그리기 버튼과 선명한 동선 표시를 제공합니다.
- 타임라인은 인물 기본 행 아래에 포즈·동작 레이어를 들여쓰기합니다. 손잡이를 드래그해 인물 묶음 또는 같은 인물의 레이어 순서를 바꿉니다. 같은 부위는 위쪽 레이어 우선입니다.
- 타임라인 키프레임/클립 선택 후 Delete로 각각 삭제하고 Undo로 복구합니다. 입력창에서 Delete는 입력 편집을 유지합니다.
- 포트8768과 sceneblock 실행 주소를 사용하여 참고 프로그램의8766/localvoicestudio와 구분합니다.
- [AI 사용 안내](docs/2026-10-23-AI-사용안내.md), [검증 기록](docs/2026-10-23-v2.6.0-verification.md)

배포: 업로드 폴더의 **내용 전체**를 저장소 루트에 올립니다. public(설치 EXE 포함)과 ai-connector(브라우저 빌드에 필요한 스키마 포함)를 함께 올립니다. Vercel build `npm run build`, output `dist`. node_modules/dist/runtime/verification은 업로드하지 않습니다. Windows 설치기는 개발 PC에서 미리 빌드된 파일이며 Vercel에서 C# 빌드를 하지 않습니다.

개발: `npm test`, `npm run build`, `npm run test:v26`, `npm run check:package`. 설치 EXE 재빌드 `npm run build:installer`는 기존 출력이 있으면 중단합니다. 런타임은 로컬 Node24.14.1과 공식 Node LICENSE가 필요합니다.

## v2.4.0 일괄 수정

- 기본 동작 위에 시간 구간별 동작·포즈 레이어를 겹칩니다. 예: 기본 걷기1–10초, 오른팔 손흔들기4–8초, 상체 뒤돌아보기8–10초.
- 인물별 기본 트랙과 레이어 트랙을 표시합니다. 블록 선택·드래그 이동·양끝 트림, 적용 부위·강도·들어오기/풀리기 시간·이름·순서·사용 여부·삭제를 편집합니다.
- 포즈 레이어 적용은 기본 동작을 지우지 않습니다. 전신 정지 포즈로 바꿀 때만 별도의 정지 포즈로 적용 버튼을 누릅니다.
- 카메라 컷이 맞닿은 경계를 드래그하면 양쪽 컷의 종료/시작 시간이 함께 바뀝니다. 최소0.1초, 바깥 경계는 보존합니다. 떨어진 컷은 기존 트림 방식을 사용합니다.
- 처음 제목은 제목 없는 장면입니다. 상단 이름을 클릭하여 수정하고 Enter/확인으로 저장, Esc/취소로 복귀합니다. 장면 구성 시 이름은 유지합니다.
- 기존 카메라13운용, 한글 포즈121개, 소품9종, 동선 그리기/시간연동, 저장·열기·영상 출력은 유지합니다.

## 조작 방법

장면 설명의 규칙 파서로 초기 장면을 만들거나 인물·소품을 직접 추가합니다. 현재 자연어 기능은 GPT가 아닙니다.

인물을 선택하고 위에서 보기 → 동선 그리기를 누릅니다. 바닥 클릭으로 점을 추가하며 번호 점을 드래그해 이동합니다. 그리기 완료/Esc 뒤에는 점과 선이 숨겨집니다. 다시 동선 그리기를 누르면 기존 점을 드래그할 수 있습니다. 위에서 보기 버튼은 이전 시점으로 바뀌어 원래 구도로 돌아갈 수 있습니다.

기본 동작 순서의 걷기·달리기 시작·종료가 이동 시간에도 적용됩니다. 추가 레이어는 동선을 바꾸지 않습니다. 인물의 예전 독립 동선 시간 입력은 숨겼습니다. 종료를 줄인 뒤 행동 추가로 다음 구간을 만듭니다. 타임라인 중앙을 드래그하면 시간 이동, 양끝 핸들은 길이 조절입니다. 드래그 중 표시되는 초를 확인하세요. 빈 행동 구간은 서 있기입니다.

인물을 선택하고 재생 위치를 정한 뒤 + 동작 레이어를 누릅니다. 새 레이어는 오른팔 손흔들기로 시작합니다. 적용 부위를 전신·상체·왼팔·오른팔·머리로 선택하세요. 뒤돌아보기는 상체 또는 머리를 선택하면 이동 방향을 유지하며 돌아봅니다. 같은 부위는 위 레이어가 우선하고 다른 부위는 함께 재생됩니다. 최대16레이어, 각64클립입니다. 같은 레이어 안의 클립은 겹칠 수 없습니다.

포즈 목록은 한글/영문 검색 가능한 고정 높이 목록입니다. 포즈 레이어로 적용은 기본 트랙 선택 시 상체 포즈 레이어를 만들고, 추가 레이어 선택 시 그 레이어 클립만 바꿉니다. 정지 포즈로 적용은 선택한 기본 클립(추가 레이어 선택 시 재생 위치의 기본 클립)을 정지 포즈로 바꿉니다. 정지 포즈 위에도 켜진 레이어는 합성됩니다.

페이드는 클립당 들어오기/풀리기를 초로 지정합니다. 각각 클립 길이 절반까지 반영하며 강도와 곱해집니다. 레이어를 꺼서 기본 동작과 비교할 수 있습니다. 타임라인은 세로 스크롤되며 위 레이어부터 보여줍니다.

카메라 이름 또는 타임라인 컷을 클릭해 바로 확인합니다. 재생하면 컷 순서를 따릅니다. 컷에 배치하지 않은 카메라도 단독 미리보기가 가능하며 영상 출력은 항상 저장한 컷 순서를 사용합니다.

카메라 움직임을 선택한 뒤 거리·각도에 음수를 입력하면 반대 방향이 됩니다. 줌은 화각만, 전진·후진은 위치를 변경합니다. 직접 동선은 운용에서 카메라 동선 → 카메라 동선 그리기 → 화면 클릭으로 추가하고 XYZ 숫자로 높이를 조절합니다. 초기 그리기 평면은 카메라 시작 높이이며, 상단 위에서 보기로 경로를 잡기 편합니다. 촬영 미리보기에는 동선·조작 가이드가 숨겨집니다.

프로젝트 저장/열기로 JSON을 PC에 저장·복원합니다. 자동 저장은 없습니다. Ctrl+Z / Ctrl+Shift+Z로 실행 취소/다시 실행합니다. 영상은 편집 화면 크기의 30fps WebM이며 Chrome 데스크톱에서 검증했습니다.

## GitHub → Vercel

전체 업로드 폴더 안의 내용을 저장소 최상위에 올립니다. public도 포함합니다. 소용량 v2.4.0→v2.4.1 패치는 현재 v2.4.0 저장소의 같은 경로에 교체하고 기존 public을 유지하세요. 더 이전 버전이면 전체 소스를 권장합니다.

Vercel: Framework Vite, Root ./, Install npm ci, Build npm run build, Output dist, Node 24.x. 기본 편집에 환경변수·계정·모델 설치가 필요하지 않습니다. 이 버전은 아직 원격 GitHub/Vercel에 반영하지 않았습니다.

## 유지되는 제한

Kimodo는 별도 로컬 Python/CUDA 엔진과 모델 접근 승인이 필요한 선택 기능입니다. [엔진 안내](docs/2026-10-23-local-engine.md). 다운로드 ZIP은 기존 v2.0.0 엔진 소스이며 기본 편집에서 요청하지 않습니다. 새 모델 다운로드·GPU 생성은 이번에 실행하지 않았습니다.

그린 동선/포즈를 AI 생성 제약으로 전달, IK, 발 접지 보정, 외부 GLB 등록, 자동 충돌 검사, 원본 프로젝트 형식 호환, 출력 해상도 선택은 제공하지 않습니다. 기본 걷기·손흔들기·뒤돌아보기는 절차적 미리보기입니다. 레이어는 선택 부위의 골격 자세를 교체 혼합하며 물리/IK 기반 자연스러운 접촉을 보장하지 않습니다. 골격 자산 로드 실패 시 상자 인체는 절차 동작만 지원합니다. 캐릭터 키는 현재 모두1.75m로 정규화됩니다. 이전 프로젝트는 열 수 있지만 새 카메라 움직임과 레이어를 저장한 파일은 이전 앱에서 정상 재현하지 못할 수 있습니다. 레이어가 없는 기존 파일은 그대로 열 수 있습니다. 기존 문서에 걷기 클립과 독립 동선 시간이 다르게 저장되어 있으면 이제 걷기 클립 시간을 따릅니다. 핸드헬드는 절차적 효과이며 광학 시뮬레이션·초점 이동·충돌 회피는 제공하지 않습니다. 돌리 줌의 화각은 10–120도 범위로 제한됩니다.

Topview Studio 전체를 이식한 제품이 아니라 Three.js 독립 편집기에 공식 자산을 사용하는 앱입니다. 출처/라이선스는 public/topview-assets/LICENSE, NOTICE, 2026-10-23-pose-attribution.md와 Kimodo·Three.js/DRACO 동봉 라이선스를 확인하세요.
