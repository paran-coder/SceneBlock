# SceneBlock · 씬블록 v2.2.0

머릿속 장면을 움직여 보는 프리비즈 스튜디오.

## 이번 일괄 수정

- 타임라인 슬라이더·초 눈금·행동·카메라 트랙의 시작/끝 정렬. 세로 스크롤이 생겨도 같은 시간축을 유지합니다.
- 현재 재생 위치선, 선택 클립 강조, 이동/양끝 트림 중 시작·종료 시간 표시.
- 클립을 클릭하면 해당 인물과 행동이 오른쪽 설정에 연결됩니다. 행동 변경·삭제도 여기서 처리합니다. 카메라 컷을 클릭하면 해당 카메라를 선택합니다.
- 인물을 추가하면 구분되는 팔레트 색상을 배정하고 기본 이름 입력란 전체를 선택합니다. 바로 새 이름을 입력하면 됩니다. 인물·목록 동그라미·타임라인에 같은 색을 표시합니다.
- 포즈 121개 이름과 분류를 한글화했습니다. 한글·영문·원본 ID로 검색할 수 있으며 저장 ID는 그대로입니다.
- 기존 소품 외에 의자·벤치·소파·문·창문·계단을 추가했습니다. 위치·회전·크기·색상을 수정할 수 있는 가벼운 기본 형상입니다.
- 스페이스바 재생·정지, 우클릭 화면 이동은 유지합니다. 텍스트 입력 중에는 스페이스바가 글자 입력으로 작동합니다.

## 조작 방법

장면 설명의 규칙 파서로 초기 장면을 만들거나 인물·소품을 직접 추가합니다. 현재 자연어 기능은 GPT가 아닙니다.

인물을 선택하고 위에서 보기 → 동선 그리기를 누릅니다. 바닥 클릭으로 점을 추가하며 번호 점을 드래그해 이동합니다. 그리기 완료/Esc 뒤에도 기존 점을 드래그할 수 있습니다. 위에서 보기 버튼은 이전 시점으로 바뀌어 원래 구도로 돌아갈 수 있습니다.

오른쪽 시작·종료는 동선 이동 시간입니다. 아래 행동 순서는 별도의 행동 구간입니다. 종료를 줄인 뒤 행동 추가로 다음 구간을 만듭니다. 타임라인 중앙을 드래그하면 시간 이동, 양끝 핸들은 길이 조절입니다. 드래그 중 표시되는 초를 확인하세요. 빈 행동 구간은 서 있기입니다.

포즈 목록은 패널 안의 고정 높이 스크롤 목록입니다. 한글/영문으로 검색하고 선택 후 미리보기 아래 적용 버튼을 누릅니다. 정지 포즈이며 기본 동작·관절 각도로 보완할 수 있습니다.

카메라에서 고정·시작/종료 이동·돌리·오빗·팬·가감속·추적 인물을 설정합니다. 촬영 미리보기에는 동선·조작 가이드가 숨겨집니다.

프로젝트 저장/열기로 JSON을 PC에 저장·복원합니다. 자동 저장은 없습니다. Ctrl+Z / Ctrl+Shift+Z로 실행 취소/다시 실행합니다. 영상은 편집 화면 크기의 30fps WebM이며 Chrome 데스크톱에서 검증했습니다.

## GitHub → Vercel

전체 업로드 폴더 안의 내용을 저장소 최상위에 올립니다. public도 포함합니다. 소용량 누적 패치는 v2.1.0/2.1.1/2.1.2 저장소의 같은 경로에 교체하고 기존 public을 유지하세요. 패치에도 v2.1.1 동선/시점 수정과 v2.1.2 포즈 목록 수정이 포함됩니다.

Vercel: Framework Vite, Root ./, Install npm ci, Build npm run build, Output dist, Node 24.x. 기본 편집에 환경변수·계정·모델 설치가 필요하지 않습니다. 이 버전은 아직 원격 GitHub/Vercel에 반영하지 않았습니다.

## 유지되는 제한

Kimodo는 별도 로컬 Python/CUDA 엔진과 모델 접근 승인이 필요한 선택 기능입니다. [엔진 안내](docs/2026-10-23-local-engine.md). 다운로드 ZIP은 기존 v2.0.0 엔진 소스이며 기본 편집에서 요청하지 않습니다. 새 모델 다운로드·GPU 생성은 이번에 실행하지 않았습니다.

그린 동선/포즈를 AI 생성 제약으로 전달, IK, 행동 블렌딩·발 접지 보정, 외부 GLB 등록, 자동 충돌 검사, 원본 프로젝트 형식 호환, 출력 해상도 선택은 제공하지 않습니다. 기본 걷기는 절차적 미리보기입니다. 캐릭터 키는 현재 모두1.75m로 정규화됩니다. 이전 프로젝트는 열 수 있지만 새 소품이 포함된 파일은 이전 앱에서 열지 못할 수 있습니다.

Topview Studio 전체를 이식한 제품이 아니라 Three.js 독립 편집기에 공식 자산을 사용하는 앱입니다. 출처/라이선스는 public/topview-assets/LICENSE, NOTICE, 2026-10-23-pose-attribution.md와 Kimodo·Three.js/DRACO 동봉 라이선스를 확인하세요.
